# V0.23 設計書：中央遊戲選單、3 格存檔、DSH 兩種啟動模式、去外部依賴

這一版做了四件事：

1. **☰ 遊戲選單**（畫面正中央，Esc 也能開）：繼續遊戲、存檔／讀檔、開新遊戲、設定、結束遊戲
2. **3 格手動存檔**：自動存檔照舊，另外可以把「現在這一刻」存到第 1～3 格，之後讀回來
3. **DSH 兩種啟動模式**：插件面板只放一張小卡片，按「▶ 啟動遊戲」開全螢幕圖層（模式 A），或按「🪟 開新視窗玩」開獨立視窗（模式 B）
4. **去外部依賴化**：出貨的檔案不連 Google、CDN、Firebase、GA；新增 `npm run check:offline`

---

## 1. 遊戲選單（`src/client/pixel/ui-menu.ts`）

左上角 ☰（`.px-menu-open`）或沒有其他視窗開著時按 Esc，打開一個置中的視窗（`MODAL_KINDS` 多了 `'menu'`，跟商店、世界地圖同一套置中規則）。

```
MenuView = 'main' | 'slots' | 'new' | {load:n} | {overwrite:n} | {remove:n}

main：  標題「🐋 遊戲選單」，下面一行「❄️ 冬 第 1 天・🪙 0・❤ 0」
        ▶ 繼續遊戲 / 💾 存檔／讀檔 / ✨ 開新遊戲 / ⚙️ 設定 / 🚪 結束遊戲
        （在朋友家串門時：存檔、開新遊戲換成一行提示和「🏠 回家」）
slots： 三張存檔卡：第 N 格、存檔時間、季節天數・金幣・好感；
        [💾 存到這格] [📂 讀取] [🗑]   空格的讀取／刪除是灰的
        有存檔的格子按存 → {overwrite:n} 先問；讀取 → {load:n}；🗑 → {remove:n}
new：   「確定要開新遊戲嗎？」→ 開新遊戲（會先備份目前進度；存檔格不會動）
```

- 讀檔／開新遊戲之後呼叫 `opts.shell.reload(toast)`：重新掛載整個舞台（地圖、她的位置、側邊欄都從新存檔重畫），新舞台出現後顯示 toast（例如「📂 讀取了第 1 格」）
- 結束遊戲呼叫 `opts.shell.exit()`：
  - DSH 模式 A：關掉全螢幕圖層；模式 B：`window.close()`
  - 試玩版：舞台換成「再見畫面」（`buildGoodbye`），按「▶ 再玩一次」重新掛載
- 選單裡的字都走 i18n key（`menu.*`），簡體模式自動切換

## 2. 存檔格（`src/shared/save-slots.ts`）

```ts
SLOT_COUNT = 3
SlotFile = { version: 1, savedAt, save: PetSave }       // 整份存檔原樣存一份
SlotInfo = { slot, empty, broken?, savedAt?, summary?: { nick, coins, affection, level, season, sceneId, ageDays } }
SlotApi  = { count, list(), save(n), load(n) → PetView, remove(n), newGame() → PetView }
```

| | 試玩版（`LocalBridge`） | DSH（host） |
|---|---|---|
| 存檔格 | localStorage `<key>:slot:1..3` | `<存檔資料夾>/slots/slot-1..3.json`（先寫 tmp 再 rename） |
| 讀檔／開新遊戲前的備份 | localStorage `<key>:backup` | `save.backup.json` |
| 呼叫方式 | 直接呼叫 | `POST /api/dsh-whale-valley/bridge`，`BRIDGE_METHODS` 多了 `slotList`、`slotSave`、`slotLoad`、`slotRemove`、`newGame` |

- 讀回來的存檔把 `lastTickAt`、`lastSeenAt` 設成現在：不會因為存檔是三天前的就一次補算三天的飢餓
- 壞掉的格子顯示「⚠️ 這格讀不出來（可能壞掉了）」、不能讀取（可以覆蓋或刪除），不會讓整個選單掛掉
- host 通道只收 1～3（不然回 400 `slot must be 1-3`）；空格讀取會回錯誤 `empty slot`，選單顯示「⚠️ 沒有成功，請再試一次」
- `HostBridge.slots` 是選用的：沒有的 bridge（例如串門用的 `VisitBridge`）選單就不顯示存檔

## 3. DSH 兩種啟動模式

### 為什麼改

V0.22 是插件一載入就在 DSH 視窗裡放一個常駐浮層，會擋到 DSH 自己的畫面。V0.23 改成插件面板只放一張小卡片（`src/client/launcher.ts`），玩家自己決定什麼時候開。

### 不跟 DSH 樣式打架的做法

- **全部用 inline style**，不在 `<head>` 插入任何全域 CSS 規則；遊戲本身的 CSS 只用 `.px-` 前綴，啟動器用 `.whale-` 前綴
- 全螢幕圖層掛在 `<body>` 最後面（不放在 DSH 的元件樹裡），所以不受 DSH 版面的 `overflow`、`transform`、`z-index` 影響
- 打開時把 `<html>` 的 `overflow` 設成 `hidden`（防止背後的 DSH 捲動），關掉時**還原成原本的值**
- 簡體模式：`i18n().install()` 支援多個根節點，只轉遊戲自己的節點，不碰 DSH 的字

### 模式 A：全螢幕圖層

```html
<!-- DSH 插件面板裡（React 元件 WhalePetPanel 只放一個空 div，交給 mountDshLauncher） -->
<div class="whale-launcher" style="display:grid;gap:10px;padding:14px 16px;width:max-content;max-width:92vw;
     background:#2d2238;border:3px solid #6b3f22;border-radius:12px;color:#fff3d6;
     font:14px/1.4 system-ui,'PingFang TC','Noto Sans TC','Microsoft JhengHei',sans-serif">
  <div style="font-weight:800;font-size:17px">🐋 鯨魚谷物語</div>
  <div style="opacity:.85;font-size:13px">她在小鎮等你回來</div>
  <div style="display:flex;gap:8px;flex-wrap:wrap">
    <button type="button" style="…">▶ 啟動遊戲</button>
    <button type="button" style="…">🪟 開新視窗玩</button>
  </div>
  <div style="display:none;font-size:12.5px;color:#ffd86b"><!-- 提示：已在另一個視窗／被擋 --></div>
</div>

<!-- 按下「▶ 啟動遊戲」後，掛在 <body> 最後面 -->
<div class="whale-fs-layer" role="dialog" aria-modal="true" aria-label="鯨魚谷物語"
     style="position:fixed;inset:0;width:100vw;height:100vh;z-index:9999;overflow:auto;
            display:flex;align-items:center;justify-content:center;box-sizing:border-box;padding:48px 16px 16px;
            background:radial-gradient(ellipse at 50% 30%,#3a2c4d 0%,#1d1528 70%)">
  <div class="whale-fs-game" style="width:min(1320px,96vw);margin:auto">
    <!-- 遊戲舞台（.px-stage）掛在這裡 -->
  </div>
  <button type="button" class="whale-fs-close"
          style="position:fixed;top:10px;right:14px;z-index:10000">❌ 關閉遊戲</button>
</div>
```

```
openFullscreen():
  如果 layer 已經存在或正在開 → return
  prevOverflow ← html.style.overflow
  layer ← 建立上面的 .whale-fs-layer，append 到 document.body
  html.style.overflow ← 'hidden'
  game ← mountGame(layer 裡的 .whale-fs-game, onExit = closeFullscreen)
  ❌ 按鈕 → closeFullscreen()

closeFullscreen():
  game.dispose()            // 停掉 render loop、輪詢、音樂
  layer.remove()
  html.style.overflow ← prevOverflow
  啟動器的按鈕 focus 回來
```

### 模式 B：獨立視窗

```
openWindow():
  url ← '/api/dsh-whale-valley/play'
  如果 win 還開著 → win.focus()，return
  如果全螢幕開著 → closeFullscreen()        // 同一份存檔不要兩邊一起玩
  win ← window.open(url, 'WhaleValley',
          'width=1280,height=720,menubar=no,toolbar=no,location=no,status=no')
  如果 win 是 null → 在卡片上顯示「瀏覽器擋了彈出視窗，請允許後再按一次」
  否則 → 卡片顯示「🪟 遊戲已經在另一個視窗打開了」
```

新視窗的頁面由 host 提供（`src/host/window-page.ts`），同一個網域，所以 DSH 的 cookie 驗證照樣有效：

| 路徑 | 內容 |
|---|---|
| `GET /api/dsh-whale-valley/play` | `WINDOW_HTML`：只有 `#app`、內嵌樣式、空白 favicon（`data:,`），沒有任何外部資源 |
| `GET /api/dsh-whale-valley/play/boot.js` | `BOOT_JS`：最小的 `window.__ModuleLoader__` 墊片＋react / jsx-runtime 空殼，載入 client 後呼叫 `bootWindowGame(#app)` |
| `GET /api/dsh-whale-valley/play/client.js` | 就是 `lib/client.js`（跟 DSH 載入的同一份） |

```
bootWindowGame(app):
  i18n().install(document.body)
  mountDshGame(app, onExit = () => window.close())
```

兩個模式用同一個 host 存檔：在 A 存到第 2 格，B 打開就看得到。

## 4. 去外部依賴化

| 檢查項 | 結果 |
|---|---|
| Google Fonts（`fonts.googleapis.com`、`fonts.gstatic.com`） | 沒有。字型全用系統字：`system-ui, sans-serif`；日記用 `"Kaiti TC","STKaiti","BiauKai","DFKai-SB","KaiTi",serif`；等寬用 `ui-monospace,Consolas,monospace` |
| CDN（unpkg、cdnjs、jsdelivr、esm.sh） | 沒有。所有程式由 esbuild 打包進 `lib/` 和試玩版 html |
| Firebase、Google Analytics、gtag | 沒有 |
| 圖片、音樂 | 試玩版：圖片內嵌（data URI），音樂讀同資料夾的 `music/`；DSH：走 host 的 `/music/<檔名>` |
| 外部網址 | 只剩 `api.deepseek.com`（AI 對話，玩家自己填 Key 才會連）；`www.w3.org` 是 SVG 命名空間字串，不會連線；`127.0.0.1` 是 host 解析網址用的假主機 |
| 聊天室 | 預設本地模擬，不連網；`?dev&chat=ws://…` 才會連自己架的伺服器 |

**實測**：用 Playwright 擋掉所有非 `file:` 的請求打開 `demo/pixel-standalone.html`，結果是 0 個對外請求、0 個網頁字型、沒有錯誤，選單和遊戲都正常。

**自動檢查**：`npm run check:offline`（`scripts/check-offline.mjs`），會掃 `lib/`、`demo/*.html`、`src/`、`locales/`：

- 黑名單：Google Fonts / Google API、境外 CDN、Firebase / GA / gtag、CSS 遠端 `@import`、遠端 `<script src>` / `<link href>`
- 出貨檔（`lib/`、`demo/*.html`）裡的網址只允許 `api.deepseek.com`、`www.w3.org`、`127.0.0.1`、`localhost`

有問題就 exit 1。
