# V0.11 設計書：廚房、浴室、遊戲室（掛機時她自己去玩遊戲）

擁有者畫了三張房間圖（`開發/溫馨海洋風像素廚房.png`、`溫馨鯨魚主題日式溫泉浴室.png`、`海洋遊戲玩家的像素房間.png`）。這一版把它們做成三個新場景，每個房間都有可以點的家具。

**重點是遊戲室**：主人一段時間沒操作（掛機），她會自己跑去遊戲室打電動。主人回來點她，她會停下來，說玩了多久、打到第幾關，同時結算好感和體力。

---

## 1. 三個房間怎麼去

| 從哪裡 | 怎麼去 |
|---|---|
| 鯨魚娘的房間 | 點最下面的門口 → 選單：🌷 花園／🍳 廚房／♨️ 浴室／🎮 遊戲室 |
| 新的三個房間 | 點最下面的走廊 → 選單：🐋 房間／另外兩個房間／🌷 花園 |
| 任何地方 | 🗺️ 地圖：三個房間在最左邊一排 |

**做法**：門的熱區可以寫 `options`（好幾個目的地）。載入時每個目的地各變成一扇門（id 是 `hall`、`hall#kitchen`…，站位相同），所以尋路、世界地圖都知道這裡通到哪些地方。點門口時跳出選單問要去哪；主人自己走（P 模式）踩到門口時，去第一個目的地。

```jsonc
{
  "id": "hall", "name": "走廊", "rect": {…}, "stand": {…}, "blocks": false,
  "action": {
    "type": "door", "to": "room", "spawn": "fromHall",
    "options": [
      { "to": "room",    "spawn": "fromHall", "label": "🐋 鯨魚娘的房間" },
      { "to": "kitchen", "spawn": "fromHall", "label": "🍳 廚房" },
      …
    ]
  }
}
```

三個房間只有背景圖，沒有 Tiled 地圖：`scenes.json` 裡不寫 `map`，載入時直接用 `interactables.json` 建出格子地圖（擺家具要用的圖塊集借第一張地圖的）。

## 3. 玩遊戲與掛機

### 規則（host，`src/shared/gameplay.ts`）

```ts
case 'play':       // 開始玩：記下哪一台、從什麼時候開始（存在存檔的 game.play）
  if (!leisure.play.games[a.game]) return fail('unknown');
  if (g.play) return ok(g, …);                       // 已經在玩：不重新開始
  return ok({ ...g, play: { game, since: now } }, { type: 'play_started', … });

case 'stop_play':  // 結算
  hours  = min(maxHours, (now - since) / 1 小時)
  好感   = min(hours × affectionPerHour, maxAffectionPerSession, 今天剩下的好感額度)
  體力   = min(體力上限, 體力 + hours × staminaPerHour)   // 玩遊戲也算休息
  關卡   = 1 + hours × levelsPerHour                       // 台詞用的，好玩而已
  return ok({ ...g, play: null, … }, { type: 'play_stopped', minutes, gain, stamina, level });

case 'sleep':      // 睡覺會停止玩遊戲（畫面會先結算再睡）
```

**存在 host 的存檔裡**：她在玩的時候關掉視窗也沒關係，重新打開她還坐在懶骨頭上；結算時用真實經過的時間（最多 `maxHours`）。

### 畫面（`pixel-stage.ts`）

```ts
// 掛機偵測：document 上的 pointerdown／keydown／wheel／pointermove（每秒最多記一次）
每一幀 checkAfk(now):
  if (afkMinutes 分鐘沒操作 && 沒在玩 && 她在家（不在礦洞）&& 沒有在走路／對話／開面板／釣魚)
    說一句 afkGo（「主人好像在忙……那我去遊戲室玩一下喔！」）
    尋路走去遊戲室（找不到路就黑幕直接過去）→ approach(電視) → startPlay('console')

玩的時候：
  - 坐在懶骨頭前（pose: sit），作息不會叫她走開
  - 每 25～45 秒冒一句 playing 台詞或音符
  - 點她、或點畫面任何地方 → stopPlay()：toast「🎮 玩了 90 分鐘：❤ +6　⚡ +12」＋ playEnd 台詞
    （不到 1 分鐘就叫停，用 playQuit 台詞）
  - 換場景、睡覺 → 先安靜結算
  - 重新整理：存檔裡還在玩 → 直接坐回遊戲機前
```

### 數值（`packs/whale-girl-pixel/leisure.json`）

| 欄位 | 值 | 意思 |
|---|---|---|
| `bath.stamina` | 30 | 泡澡回多少體力 |
| `bath.affection` | 3 | 泡澡加多少好感 |
| `bath.cooldownHours` | 6 | 多久能再泡（遊戲時間） |
| `play.affectionPerHour` | 4 | 玩一小時加多少好感 |
| `play.maxAffectionPerSession` | 10 | 一次最多加多少 |
| `play.staminaPerHour` | 8 | 玩一小時回多少體力 |
| `play.maxHours` | 8 | 最多算幾小時（掛機一整晚也只算 8 小時） |
| `play.levelsPerHour` | 6 | 每小時破幾關（台詞用） |
| `play.afkMinutes` | 3 | 幾分鐘沒操作她就自己去玩（0 = 不會自己去） |
| `lines.*` | — | 泡澡、冷卻、開始玩、玩的時候、結束、太快叫停、自己跑去玩 |

廚房的水龍頭：`stats.json` 的 `satiety.drink.taps: ["tap"]`（不是釣魚點的水源）。

## 4. 新的熱區動作

| `action.type` | 參數 | 做什麼 |
|---|---|---|
| `drink` | `table` | 喝水（`stats.json` 的 `drink.tables` 或 `drink.taps`） |
| `bath` | — | 泡澡 |
| `play` | `game` | 開始玩遊戲（`leisure.json` 的 `play.games`） |
| `door` | `options[]` | 一個門口好幾個目的地（選單） |
| `show_dialogue` | `lines` | 新增 `{time}`、`{weather}`、`{season}` 變數 |

`check-pixel` 會檢查 `play` 的遊戲、`drink` 的水源、門的每個目的地是否存在。

## 5. 注意

- **檔案大小**：
  - 三張房間圖縮成 1152×768 的 WebP，每張約 250 KB（畫面最多只用到這麼大；熱區座標照樣用原圖 1536×1024 的像素）。
  - 雙擊版變成約 4.2 MB。
- **遊戲室圖上有別人的角色**：收藏櫃上有草帽骷髏旗和機器人頭，地上有問號磚和蘑菇，看得出來是現有作品的角色。自己玩沒關係；**公開發布前要把這幾處重畫**。
- **作息照舊**：她到了新房間，時段一換（例如早上變下午），還是會照作息走去花園；只有玩遊戲時會一直待著。
