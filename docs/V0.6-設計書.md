## 0. UI：所有介面都在地圖旁邊的側邊欄（V0.6.1）

V0.6 第一版是「右側抽屜」，但狀態列、任務框、右上角按鈕、收合後的標籤還是蓋在地圖上。V0.6.1 改成地圖和介面分開：

```
┌──────────────── 地圖（整數倍放大） ────────────────┐┌── 側邊欄 ──┐
│  她、寵物、頭頂氣泡、指引箭頭、字幕（對話框）          ││ ⟩收起 鯨魚娘 │
│  ── 只有「遊戲裡的東西」畫在地圖上 ──                 ││ 狀態列       │
│                                                       ││ 按鈕（🎒🗺️…）│
│                                                       ││ 📌 當前任務  │
│                                                       ││ 戰鬥血量／裝修提示 │
│                                                       ││ 面板（揹包、商店…）│
│                                                       ││ 提示訊息     │
└───────────────────────────────────────────────────────┘└────────────┘
```

- **側邊欄裡**：狀態列、按鈕、當前任務、戰鬥血量、裝修模式提示、所有面板、提示訊息。
- **地圖上只留遊戲裡的東西**：她和寵物、頭頂氣泡、指引箭頭、滑鼠提示、對話框（字幕），還有女神、釣魚小遊戲這種事件畫面。
- **面板**：
  - 在側邊欄裡展開，開著面板也能點地圖。
  - 標題列的「－」可以把面板收成一行標籤，點標籤再展開。
- **側邊欄本身可以收起來**：
  - 按最上面的「⟩ 收起」，只留一排按鈕，地圖會變大。記住上次的狀態。
  - 收起時如果打開面板，側邊欄會自動展開。
- **寬度分配**：地圖依剩下的寬度選最大的整數倍放大，側邊欄拿剩下的寬度（230～420px）。容器很窄（< 620px）時，側邊欄排到地圖下面。
- **快捷鍵**（B、C、K、M、Esc…）：焦點在側邊欄時也能用；在輸入框打字時不會被搶走。

### 1.1 介面（`gameplay-types.ts`）

```ts
interface PetsFile {
  version: 1;
  maxPets: number;              // 最多養幾隻
  defaultHome: string;          // 寵物平常在哪張地圖閒逛
  shop: ShopId;                 // 寵物店的商人 id（賣飼料、捕捉網；寵物本身列在面板上）
  affection: { max: number; petGain: number; feedGain: number; skillBonusAtMax: number };
  satiety: { max: number; start: number };
  wild: { blockHours: number; chance: number; weatherBonus?: Record<string, number> };
  species: Record<string, PetSpeciesDef>;
  items?: ItemDef[];            // 飼料、捕捉網（載入時併進物品清單）
}

interface PetSpeciesDef {
  name: string; emoji: string; description?: string;
  sprite?: {                                                    // 貼圖（存成 3 倍大，畫 1/3）
    src: string; scale?: number;
    float?: boolean;                                            // 會飄（水母、小精靈）
    faces?: 'left' | 'right' | 'front';                         // 圖裡面朝哪邊；往另一邊走就翻轉
    sheet?: { frameWidth; frameHeight; frames; walk: number[]; idle: number; fps };   // 走路圖
  };
  shop?: { price: Cost };                                       // 商店購買
  wild?: {                                                      // 野外捕捉
    scenes: string[];         // 出現在哪些地圖
    weather?: string[];       // 天氣 id 或 tags（雷雨有 "rainy" tag，所以寫 rainy 也包含雷雨）
    phases?: DayPhase[];      // 時段
    seasons?: SeasonId[];
    weight: number;           // 同一張地圖有好幾種時的權重
    catchRate: number;        // 捕捉率（0～1），再乘上網子的 power
    flee: number;             // 沒抓到時逃跑的機率
  };
  diet: { item?: ItemId; category?: string; satiety: number }[];  // 吃什麼、一次加多少飽食度
  satietyDecay: number;       // 每小時掉多少飽食度
  speed: number;              // 走路速度（格／秒）
  home?: string;
  skill: PetSkillDef;
}

type PetSkillKind = 'auto_pickup' | 'crow_guard' | 'fishing_luck' | 'water_plots' | 'mine_luck';
interface PetSkillDef {
  kind: PetSkillKind; name: string; description: string;
  radius?: number; perDay?: number;              // auto_pickup：看得到多遠、離線時一天撿幾個
  crowMult?: number;                             // crow_guard：烏鴉機率剩幾成
  rare?: Partial<Record<Rarity, number>>;        // fishing_luck、mine_luck：稀有倍率
  plots?: number;                                // water_plots：每天早上澆幾塊
}

ItemDef.net?: { power: number }                  // 捕捉網

// 存檔
interface PetState { id; kind; name; affection; satiety; lastPetDay; obtainedAt; how: 'shop' | 'wild' }
GameState.pets: PetState[]; nextPetId; companion: number | null   // 跟班
GameState.forage: { dayAt; picked }              // 今天撿過哪些掉落物
GameState.wild: Record<spawnId, 'caught' | 'fled'>
GameState.farmReport: { day; pecked; scared; watered; picked } | null   // 今天早上的農場事件
```

## 2. 跟隨移動與隨機閒逛（`pets-client.ts`）

```ts
// 誰在這張地圖：跟班在主人身邊；其他的在自己的 home 地圖
petsHere = pets.filter(p => (p.id === companion && leader) || p.home === sceneId)
leader   = 主人自己走（P）? 主人 : 她去礦洞了 ? null : 鯨魚娘

每一幀 update(dt):
  // 1. 記下主人走過的格子（最多 6 格）：跟班走到「主人剛離開的那一格」，不會疊在主人身上
  if leader.tile 變了: trail.push(leader.tile)

  for p in petsHere:
    a = actors[p.id] ?? spawnActor(p)          // 換地圖時：跟班出現在主人旁邊，其他的放在固定位置
    chasing = p 是跟班 and (leader 在走 or 曼哈頓距離 > 3)
    if chasing: follow(a, leader)
    if a.walking: 沿著 path 一格一格走，速度 = species.speed × (餓了 0.6) × (跟班落後 >3 格時 1.6)
    else if !chasing and now ≥ a.idleUntil: decide(a, p, 跟班 ? leader.tile : null)

follow(a, leader):
  d = manhattan(a.tile, leader.tile)
  if d > 12: 直接出現在 trail 倒數第二格（跟丟了就瞬移，不卡牆）
  if d ≤ 1: 原地等
  target = trail 裡最後一格不是主人腳下的格子
  if 沒在走 or 路徑終點 ≠ target，且距離上次規劃 > 250ms:
      path = findPath(map, a.tile, target)      // A*，4 方向，跟鯨魚娘同一套
      走不到就改成走到主人那格

decide(a, p, near):                              // 閒逛
  if 技能是 auto_pickup 且沒餓:
      dist = BFS(map, a.tile)
      best = 這張地圖的掉落物裡，dist ≤ radius、最近、還沒有人去撿的那個
      if best: 走過去，goal = forage，頭上冒「❗」；return
  中心 = near ?? a.tile；範圍 = near ? 2 格 : 4 格
  隨機挑最多 8 次範圍內走得到、路徑 ≤ 8 格的格子 → 走過去
  走不了就發呆 1.5～5 秒，偶爾冒 ♪ / 💤（貓）/ 🍖（餓了）

到達終點時:
  if goal == forage 且那格還有東西: host.dogPickup(spot, pet.id)   // 送 act({ type: 'forage', by: petId })
```

**繪製**：
- 貼圖存成 3 倍大，畫的時候縮成 1/3，跟居民、鯨魚娘一樣。
- 有走路圖的（狗、貓）：走路時依 `sheet.walk` 輪播，停下來用 `sheet.idle`。圖面向右，往左走就左右翻轉。
- 靜態圖：呼吸縮放；走路時一跳一跳。
- 會飄的寵物（水母、小精靈）上下浮動、影子比較小。
- 跟班頭上有 ⭐。
- 跟鯨魚娘依 y 座標排前後，站在她前面的就畫在她前面。

## 3. 野生寵物的刷新與捕捉判定（`pets.ts`）

```ts
// 刷新：一天切成 blockHours（2 小時）一段，每段、每張地圖擲一次。結果只看時間，不吃存檔亂數
wildAt(scene, now):
  block = floor((now - 今天 0 點) / blockHours)
  id    = `${dayIndex}:${block}:${scene}`
  if save.wild[id]: return null                         // 這段時間已經抓到或跑掉了
  mid   = 這一段的中間時間（整段時間判斷結果一致）
  tags  = [weatherAt(mid), ...weatherDef.tags]           // 例如 ['storm', 'rainy']
  pool  = species.filter(s => s.wild 且 scenes 含 scene
                              且 (沒寫 weather 或 weather ∩ tags ≠ ∅)
                              且 (沒寫 phases 或含 dayPhase(mid))
                              且 (沒寫 seasons 或含 seasonAt(mid)))
  if pool 空: return null
  rng   = rngFrom(hash('wild:' + id))
  bonus = max(1, tags 對到的 wild.weatherBonus)          // 雨天 ×1.5
  if rng() ≥ wild.chance × bonus: return null            // 雨天海邊實測出現率 ≈ 60%
  kind  = 依 pool 的 weight 抽一種
  return { id, scene, kind, until: 這一段結束 }

GameView.wild = 所有「有野生寵物會出現」的地圖各算一次
畫面：位置 = hash(id) 挑一格可以站、不擋門和互動物件、不被狀態列蓋住的格子；
      頭上閃 ✨，滑鼠移上去顯示「野生的水母（點一下用捕捉網抓）」

// 捕捉
點野生寵物 → 側邊欄列出每一種網子：「丟 🎐 絲綢捕捉網（成功率 63%，有 3）」
選網子 → 網子在牠頭上晃 1.1 秒 → act({ type: 'catch_pet', scene, spawn: id, net })

host run('catch_pet'):
  state.act 先檢查 scene == 她現在的地圖，不是就回 not_here
  spawn = wildAt(scene, now)；不存在或 id 不同 → gone（時間過了、或已經抓過）
  沒有這種網子 → no_item；寵物滿了 → too_many_pets
  chance = clamp(species.wild.catchRate × net.power, 0, 0.95)
  inventory[net] -= 1                                    // 丟出去就用掉
  if rnd() < chance:
      新增寵物（how: 'wild'）；save.wild[id] = 'caught'   → pet_caught
  else:
      fled = rnd() < species.wild.flee
      if fled: save.wild[id] = 'fled'                    → pet_escaped { fled: true }：「💨 跑掉了」
      else:                                              → pet_escaped { fled: false }：「差一點！要再丟一次嗎？」
                                                            （捕捉面板自動再打開）
```

跟天氣系統的結合點：
- 天氣用的是 V0.5 的 `weatherAt`／`weatherDef`，所以 `weather.json` 新增的天氣只要加上 `tags`，就能被寵物的 `wild.weather` 條件用到。
- 雨天加成寫在 `pets.json` 的 `wild.weatherBonus`。
- 「⏭ 跳到明天」或睡覺快轉之後，天氣和時段都會變，野生寵物也跟著換。

## 4. 被動技能與農場系統的觸發點

共同規則（`bestSkill`）：
- 同一種技能只算最強的那一隻。
- 餓了（飽食度 0）技能就停。
- 強度 power = 1 + 好感/1000 × `skillBonusAtMax`（0.5），所以好感滿時是 1.5 倍。

```ts
power(p) = 1 + clamp(p.affection, 0, max) / max × skillBonusAtMax
```

### 4.1 狗：撿東西（`auto_pickup`）

```ts
// 畫面開著：見第 2 節 decide()。狗走到掉落物上 → act({ type: 'forage', scene, slot, by: dog.id })
host run('forage'):
  spot = 今天的掉落物裡 (scene, slot) 還沒撿的；沒有 → gone
  if by: 那隻寵物要有 auto_pickup 而且沒餓，否則 unknown
  inventory[spot.item] += 1；forage.picked[scene:slot] = true   → foraged { by }
  畫面：「🐕 柴犬撿回來 🫐 野莓！」，狗跳一下

// 畫面關著：tickGame 跨日時
if forage.dayAt ≠ 今天:
  dog = bestSkill('auto_pickup')（用跨日那一刻的飽食度判斷）
  if dog: 從昨天的掉落物裡挑還沒撿的，最多 round(perDay × power) 個 → 放進揹包、記在 farmReport.picked
  forage = { dayAt: 今天, picked: {} }
```

掉落物本身是 `forageFor(某一天, defs)`，只看日期，用 `hash('forage:' + 日期 + 地圖)` 當種子：每個位置擲 `chance`，再依掉落表抽（跟釣魚同一套 `rollLoot`，可以寫季節、天氣條件）。

### 4.2 貓：趕烏鴉（`crow_guard`）、小精靈：晨露（`water_plots`）

這兩個都在 `tickFarmAndPets` 的「每個早上」迴圈裡。V0.6 順便把田的結算改成**逐個早上**算：先把田結算到那個早上，再澆水。以前是先結算到現在才補澆水，中間那段生長會算成乾的。

```ts
for t in mornings(lastTickAt, now, wakeHour):       // 這段時間經過的每個早上 6 點（離線、睡覺快轉都會經過）
  1. 每塊田 settlePlot(到 t)
  2. 下雨（weatherDef.wet）：全部澆好到 t + 1 天
  3. 小精靈：fairy = bestSkill('water_plots', t 當下的飽食度)

  4. 烏鴉：targets = 戶外有作物的田（溫室、灑水器不算）
     if targets.length ≥ crows.minCrops:

                                       farmReport.pecked.push(plot)

畫面：每天第一次看到 farmReport → 提示「🌅 今天早上：💧 寵物幫忙澆了 2 塊田；🐈 貓咪趕走了 1 隻烏鴉」
```

### 4.3 水母：幸運微光（`fishing_luck`）、鼴鼠：挖寶鼻（`mine_luck`）

```ts
petRareMult(kind):
  s = bestSkill(kind)；沒有 → 全部 1
  epic、legendary 各自 = 1 + (skill.rare[r] - 1) × power   // 好感只放大「超過 1 的部分」

釣魚 rareMultipliers = 魚竿 × 魚餌 × (1 + 天氣加成) × 女神好運 × petRareMult('fishing_luck')
礦洞 simulateMine 的掉落權重 = 女神好運 × petRareMult('mine_luck')
```

V0.5 時礦石、寶石沒有寫稀有度，所以女神的好運其實沒有作用在礦洞。V0.6 補上了：金礦、紫水晶、紅寶石、水晶劍、水晶鎧是史詩，鑽石是傳說。

### 4.4 照顧寵物

| 動作 | 規則 |
|---|---|
| `buy_pet` | 只能買有 `shop` 的種類；扣價格；超過 `maxPets` → `too_many_pets`；名字重複會自動加數字 |
| `feed_pet` | 食物要符合 `diet`（物品或分類），否則 `not_food`；快滿了 → `not_hungry`；飽食度 + `diet.satiety`、好感 + `feedGain` |
| `pet_pet` | 一天一次，好感 + `petGain`（點畫面上的寵物就是摸摸） |
| `set_companion` | 指定跟班，或設成 null 讓大家回家 |
| `release_pet` | 放生（面板上要按兩次確認）；是跟班的話一併取消 |

## 5. 擴充：mod 加寵物

```json
{ "version": 1,
  "petSpecies": {
    "frog": { "name": "青蛙", "emoji": "🐸",
      "wild": { "scenes": ["garden"], "weather": ["rainy"], "weight": 5, "catchRate": 0.5, "flee": 0.2 },
      "diet": [{ "category": "fish", "satiety": 20 }], "satietyDecay": 2, "speed": 2,
      "skill": { "kind": "crow_guard", "name": "吃蟲", "description": "…", "crowMult": 0.6 } } } }
```

檢查（`validatePets`）會擋下這些錯誤，有錯的 mod 整個跳過：
- 技能種類不對、`diet` 是空的、`shop` 和 `wild` 都沒有（拿不到）、捕捉率或逃跑率不在 0～1。
- 寵物店不存在、網子 `power` ≤ 0、掉落表的物品不存在、烏鴉機率不在 0～1。

`npm run check:pixel` 會一起檢查寵物貼圖有沒有放。

## 7. 說明與限制

- **貼圖**：
  - 柴犬、橘貓用你提供的走路圖（2×2 四格）：
    - 處理方式：綠幕去背、去影子、裁掉「豆包 AI生成」浮水印，四格對齊排成一列。
    - 走路時輪播，往左走就左右翻轉。
    - 柴犬第四格的毛色是米白色、跟前三格不一樣，所以只用前三格（走路順序 0→1→2→1）。
  - 水母、小精靈、鼴鼠是程式用像素格畫的暫時圖。
  - 換圖時改 `pets.json` 的 `sprite`：`src` 是圖檔，`sheet` 是走路圖的格子大小、格數、走路順序、站著用哪格。
- **地圖大小**：地圖只用整數倍放大（像素才不會糊）。視窗寬度不夠讓地圖放大到下一倍時，地圖旁邊會留一點空白。
- **小精靈只在傍晚和晚上出現**。白天想抓的話，demo 可以用「⏩ 快轉 3 小時」。
- **烏鴉只看「戶外種了幾塊」**：剛開始玩、只種幾塊田的時候不會來，新手引導不受影響。
