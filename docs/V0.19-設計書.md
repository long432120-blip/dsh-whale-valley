# V0.19 設計書：天氣一次一種（冬天下雪、不跟雨混）、好感放慢

## 1. 天氣一次一種

**問題**：冬天下雨的日子，畫面同時有雨滴（天氣粒子）和雪花（V0.18 的冬天季節粒子），看起來又下雨又下雪。其他季節下雨時，花瓣、落葉也跟雨一起飄。

**改法**：同一時間畫面上只會有一種東西在飄。

| 狀況 | 畫面 |
|---|---|
| 晴天 | 季節粒子：春天櫻花、夏天螢火蟲、秋天落葉；冬天晴天不飄東西 |
| 雨天、雷雨 | 只有雨滴（季節粒子不出現；`rainRatio` 預設改成 0） |
| 雪天（新） | 只有雪花（60 片），不畫雨滴 |

### 1.1 新的天氣：雪天（`weather.json`）

```jsonc
{ "id": "snowy", "name": "雪天", "emoji": "❄️", "wet": true, "tint": "rgba(205,220,245,0.12)" }
"winter": { "sunny": 6, "rainy": 0, "storm": 0, "snowy": 4 }   // 原本 sunny 8、rainy 2
```

- **冬天**：只會晴天或下雪，不會下雨；其他季節不下雪。
- **田**：雪天跟雨天一樣，早上會自動澆好（`wet`）。
- **雪天不算下雨**：只在雨天出現的東西，例如雨天的螃蟹、鰻魚、雨天海邊的水母、雨天加成，雪天不會出現；背景音樂也不會換成下雨那首。

### 1.2 雪花從季節粒子搬到天氣粒子（`scenes.json`）

```jsonc
"ambient": {
  "seasons": { "spring": { "kind": "petal", … }, "summer": { "kind": "firefly", … }, "autumn": { "kind": "leaf", … } },
  "weather": { "snowy": { "kind": "snow", "count": 60, … } }   // 新：天氣 id → 粒子
}
```

畫面每一幀的選法：

```
weatherKey = 'weather:' + 今天的天氣
if 天氣有自己的粒子（雪天）  → 畫天氣的粒子
else if 天氣有雨滴（雨天、雷雨） → 什麼都不飄（只有雨）
else                          → 畫季節的粒子
```

### 1.3 其他

- **時間天氣木牌**：雪花圖示用在雪天，冬天的季節圖示也是它（`icons.names` 的 `snow` 改名 `snowy`）。
- **日記**：雪天寫「下雪了，外面白白的。」

## 2. 好感放慢

V0.18 的模擬：認真玩的人大約兩週就能求婚，太快了。

| 設定 | 原本 | 現在 |
|---|---|---|
| 每日好感上限 | 30 | 20 |
| 熟悉 | 30 | 50 |
| 好朋友 | 90 | 150 |
| 家人 | 200 | 330 |
| 戀人 | 300 | 500 |
| 求婚（藍色貝殼） | 300 | 500 |
| 好感解鎖的台詞 | 30／90／200／300 | 50／150／330／500（跟著等級） |
| 池塘的河豚（要好感） | 90 | 150 |

小願望的獎勵（4～6）仍然不算在每日上限裡，這樣做願望比較有感。

### 2.1 模擬結果（`npm run sim -- --days 60`）

| 玩家 | 熟悉 | 好朋友 | 家人 | 戀人／可以求婚 |
|---|---|---|---|---|
| casual（一天上線一次） | 第 5 天 | 第 15 天 | 第 29 天 | 第 42 天 |
| farmer（認真種田） | 第 3 天 | 第 8 天 | 第 19 天 | 第 28 天 |
| gambler（什麼都玩） | 第 3 天 | 第 7 天 | 第 16 天 | 第 24 天 |

原本認真玩大約 12～14 天就能求婚，現在大約 4 週；一天只上線一次的人大約 6 週。

`scripts/sim-week.ts` 多了 `--days N`：超過 14 天時只印「第幾天升到哪一級、第幾天可以求婚」。
