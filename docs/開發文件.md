# 鯨魚谷物語：開發文件

> 給想改程式、做自己角色包的人。玩家與一般使用者請看 [README](../README.md)。
> 這份文件從 README 搬過來（V0.21），各版本的詳細設計在同一個資料夾的 `V0.x-設計書.md`。

鯨魚娘在房間、花園、牧場、海邊、小鎮之間生活：俯視角、Tiled 圖塊地圖、她照時段作息自己走來走去，點她會跳出對話框。
玩法：**釣魚、換種子、種菜、餵她、好感升級**；**四季與天氣、澆水與灑水器、料理、圖鑑**；
**金幣與出貨、開墾、加工機器、動物養殖、釣魚小遊戲、擺家具、溫室魚塘馬廄、小鎮居民與劇情、告白結婚、礦洞、節慶、主人自己走、禮物碼**；
之後陸續加上寵物、數值、AI 對話、背景圖房間、酒館、背景音樂、時間天氣木牌、AI 日記、小願望、摸摸頭、季節粒子（每一版的說明在下面）。

後續規劃與進度：[核心玩法計劃書](核心玩法-計劃書.md)、[核心玩法驗收清單](核心玩法-驗收清單.md)、
[擴展玩法計劃書](擴展玩法-計劃書.md)、[擴展玩法驗收清單](擴展玩法-驗收清單.md)。

## 30 秒跑 Demo（不需要 DSH）

**最快：先跑 `npm run demo:standalone`，再雙擊產生的 `demo/pixel-standalone.html`。** 角色包、地圖、圖片全部內嵌，不需要伺服器、Python 或 Node。
（V0.1 的橫向插畫版還在：`demo/standalone.html`）

**伺服器版**（改地圖或 JSON 後重新整理就生效、可以用 `?pack=` 換角色包）：在**專案根目錄**開任一個靜態伺服器

```sh
python3 -m http.server 8080        # Windows：py -m http.server 8080；或 npx serve -l 8080 .
# 像素版：http://localhost:8080/demo/pixel.html
# V0.1： http://localhost:8080/demo/
```

> 伺服器版不能雙擊打開：瀏覽器不允許 `file://` 頁面讀 JSON。

改了 TypeScript 之後：

```sh
npm install
npm run demo                       # 伺服器版：esbuild 邊改邊編（:8080）
npm run demo:standalone            # 重新產生兩個雙擊版 HTML
```

## 怎麼玩（A 方案：不操控角色，看她生活）

| 操作 | 結果 |
|---|---|
| 點她（或選取畫面後按 Enter） | 停下來、轉向你、播放動作（揮手、開心跳、慌張……依台詞而定），跳出對話框 |
| 點地面 | 她走過去（會繞過家具、池塘） |
| 點門 | 她走到門口，出門換地圖，說一句進場台詞 |
| 什麼都不做 | 照作息在幾個地點之間走動：早上在房間、下午和傍晚去花園、晚上回房間。走到地毯、池塘邊會坐下，晚上走到床邊會打瞌睡 |
| ⏩ 快轉 3 小時 | 你看著畫面時時間往前跳；時段一換，她會自己走去門口換場景 |
| 🚪 離開 3 小時再回來 | 模擬關掉畫面再打開：她已經在作息該在的地方，並跟你打招呼 |

> 第一次打開時她在房間。想馬上玩，就點右上角的門帶她去花園。

### V0.2 玩法：釣魚、換種子、種菜、餵食

| 操作 | 結果 |
|---|---|
| 點池塘 | 她走到池邊、面向池塘冒「…」，等約 3 秒（點一下可以直接揭曉）跳出「釣到了 🐟 鱸魚！」。每次花 10 體力。傍晚和晚上才釣得到河豚，好感到「好朋友」也會多一點機會 |
| 點攤位（🧳 旅行商人） | 打開交換清單：用魚或釣到的垃圾換種子。**種子只能跟商人換**，一開始沒有 |
| 點空的田 | 種下目前選的種子（揹包裡點種子可以換）；沒種子她會提醒你去找商人。每次花 5 體力 |
| 點長大中的田 | 告訴你還要多久；成熟的作物會輕輕跳動，點一下收成 |
| 🎒（或按 B） | 揹包：分類分頁。點魚或作物 → 餵她（加飽食和好感）；點種子 → 設成播種用 |
| Esc | 關掉揹包 / 商人 / 對話框 |

左上角三條：⚡ 體力（**不會自然回復**，只能靠睡覺和吃東西；起始 100）、🍙 飽食（起始 80，每小時掉 4，吃飽了就不吃）、❤ 好感與等級。
（V0.7 起數值以 `packs/whale-girl-pixel/stats.json` 為唯一來源，`gameplay.json` 裡同名的舊欄位會被 `applyStats` 覆蓋、不再生效。）
好感**每天最多 +20**（V0.19 從 30 調低；她的小願望另外算）；她最喜歡河豚和草莓（好感 ×2），討厭辣椒（不加好感）。
好感等級：初次見面 → 熟悉（50）→ 好朋友（150）→ 家人（330）→ 戀人（500）。升級時她會說「我們的關係變成『熟悉』了！」，
之後點她會多出新台詞。

### V0.3 加深：四季、澆水、料理、圖鑑

| 操作 | 結果 |
|---|---|
| 看狀態列最下面一行 | 現在的季節、這一季第幾天、今天的天氣。**現實的 7 天換一季**；Demo 可以按「⏭ 跳到明天」 |
| 點剛種下的田 | 澆水（花 2 體力，濕 12 小時）。沒澆水只有 1/4 的生長速度，田上會有閃爍的水滴 |
| 下雨天 | 花園會下雨，所有田自動是濕的；螃蟹只在雨天釣得到 |
| 跟商人換灑水器 → 揹包點它 → 點田 | 那格永久濕潤，不用再澆 |
| 播種 | 作物分季節（春：草莓、胡蘿蔔；夏：辣椒、番茄；秋：胡蘿蔔、南瓜；冬：白菜），不是當季種不下去 |
| 回房間點桌子（🍳 料理台） | 把魚和作物做成料理（壽司、果醬、沙拉、蔬菜湯、南瓜派），餵她加更多飽食和好感 |
| 📖（或按 C） | 魚類圖鑑：8 種魚的收集進度、釣到次數、在什麼季節／天氣／時段出現 |
### V0.4：核心六大系統、擴展玩法

**地圖**：房間 ⇄ 花園（右邊出口 → 牧場、下方出口 → 海邊）；牧場右邊 → 小鎮；牧場的溫室門、房間左下的梯子（閣樓）要先解鎖。
地圖邊緣的**白色箭頭**就是出口。按 🗺️（或 M）打開世界地圖，點一個地方，她會自己一張一張地圖走過去。

| 系統 | 怎麼玩 |
|---|---|
| 💰 金幣 | 牧場的 📦 出貨箱：賣 1 個或全部。狀態列最下面一行顯示金幣。商人、花店、鐵匠都收金幣 |
| 🔒 解鎖 | 地圖上有 🔒 的田、機器、建築、門：點一下看條件，夠錢就解鎖（牧場田地、果醬機、燻魚爐、工坊、熔爐、雞舍、畜棚、房屋擴建、溫室、魚塘、馬廄） |
| ⏳ 加工機器 | 果醬機、燻魚爐、工坊（牧場）、熔爐（小鎮）：放材料進去，過一段時間來拿。做好了上面冒 ✨ |
| 🐔 動物 | 點雞舍／畜棚：買雞、鴨、牛、羊、豬，🌾 餵乾草（商人、老陳有賣）、每天摸一次、收產品。心情好會出大雞蛋、上等羊毛；豬要開心才會找到松露。可以升級容量 |
| 🎣 小遊戲 | 魚上鉤時跳出橫條：在綠色區按下去（點一下或空白鍵），黃色區是完美（有機會釣到兩條）。🎒 揹包最下面可以關掉，關掉就是原本等 3 秒 |
| 🌊 釣點 | 花園池塘、海邊（海、河口）、牧場魚塘（要解鎖）；圖鑑有 18 種魚、5 組收集獎勵 |
| 🛠️ 裝修 | 🛠️ 按鈕或 R：揹包點家具拿起來、點空格擺放；沒拿東西時點家具收回。會擋住門或路的位置不給放。地板、壁紙在揹包點一下就換（舊的退回揹包） |
| 🟫 自由佈局 | 戶外可以擺「田地套組」（變成一塊能種的田）、花圃、石板路、燈籠 |
| 🌿 溫室 | 裡面 10 塊田不分季節、不用澆水 |
| 🐴 馬廄 | 解鎖後她在戶外走路變快 |
| 👧 居民 | 小鎮的小葵（花店）、阿綱（鐵匠）、老陳（漁夫，V0.5 搬到小鎮擺魚攤）：每天聊天 +好感、送禮一天一次（看喜好），每 100 好感一顆心，到門檻會觸發劇情。三位也都開店 |
| 💍 結婚 | 她的好感到 500（戀人）後，揹包會出現「告白」按鈕：送她 🐚 藍色貝殼（海邊稀有，或老陳的店）。婚後每天早上她會幫忙澆田、摸動物 |
| ⛏️ 礦洞 | 小鎮右上的洞口：選樓層「派她去」，她離開一段時間後帶回礦石和戰利品（自動戰鬥，看武器、防具）。鎬子決定能去多深（鐵匠用金屬錠換） |
| 🗡️ 即時戰鬥 | 礦洞面板「親自下去」：方向鍵移動、空白鍵／J 攻擊和敲石頭，找到 🕳️ 往下；左上梯子回地面。倒下會掉一半戰利品 |
| 🕹️ 自己走 | 🕹️ 按鈕或 P：方向鍵／WASD 走主人，她跟在後面；E 或空白鍵讓她做面前的事；站在門口再往前就出門 |
| 🎁 禮物碼 | 🎁 按鈕或 G：選東西產生禮物碼傳給朋友，朋友貼上就收到（同一張只能收一次）；也有名片碼可以互相看 |
| 🎉 節慶 | 每季第 4 天：花祭、海灘祭、豐收祭、冰釣大會。限定商品和限定魚 |

Demo 多了「⏭ 跳到明天」按鈕，方便看季節、節慶和婚後幫忙。

### V0.22：繁簡雙語、聊天室、串門、交易所、寵物領養

詳細在 [`V0.22-設計書.md`](V0.22-設計書.md)。全部不需要伺服器：玩家之間互傳「碼」。

- **多語言**（`src/client/i18n.ts`、`locales/`）：⚙️ 設定切換繁體／简体（存 localStorage，切換會重新整理）。
  新介面用語言包 key（`t('market.title')`）；其他文字（舊介面、台詞、物品、角色包、AI 回覆）在畫面上自動轉：
  先換兩岸用語（`zh-CN.json` 的 `terms`：程式碼→代码、網路→网络、預設→默认、存檔→存档、外掛→插件…），再逐字繁轉簡（`t2s-chars.json`，`tools/gen_t2s.py` 產生）。
  DOM 用 MutationObserver，畫布只包自己那個 context 的 `fillText`；DSH 版只轉插件自己的區塊。
- **聊天室**（`src/client/chat.ts`）：💬 側邊欄，標明「本地模擬」，居民和旅人照 `social.json` 的關鍵字回覆；
  髒話過濾（`src/shared/profanity.ts`，擋夾符號、全形、大小寫，有白名單）；限速、防洗版；`connectToServer(url)` 接 WebSocket，連不上自動退回本地模擬。
- **碼**（`src/shared/codec.ts`）：`WV1.<種類>.<j|z>.<Base64URL>.<校驗碼>`；改過的碼一律「無效」。
  校驗碼的 salt 是公開的，所以真正擋作弊的是規則層（`src/shared/trade.ts`、`social-rules.ts`）：範圍檢查、一張碼只能用一次、轉移不複製、期限。
- **交易所**（🏪）：今日市集（每天同一批、限量）、我的攤位（上架時物品先扣掉保管、產生攤位碼）、買朋友的貨（產生收款碼）、收款（只能一次）。
- **寵物領養**：寵物面板「送養」產生領養碼，寵物離開你家；好感、飽食跟著過去；24 小時只能送一次。
- **串門**（`src/client/game-shell.ts`、`visit.ts`）：⚙️ 設定的「🏡 生成邀請碼」「🚪 去朋友家」打開畫面中央的串門視窗（`buildVisitModal`，一鍵複製、前往朋友的農場）；朋友貼上後畫面換成 `VisitBridge`（記憶體裡的唯讀副本，不碰存檔），
  只能點她說話、走動、幫忙澆水、✉️ 留信（回信碼）；🏠 回家換回原本的存檔。主人在 📮 信箱貼回信碼，收到信、當天澆的田也算數。
- **資料**：`packs/whale-girl-pixel/social.json`（鹽、市集、攤位價格範圍、期限、冷卻、聊天機器人、詞庫）。
- **入口**：單機版和 DSH 版都改用 `mountGame()`（包住 `mountPixelStage`，負責串門切換和聊天室）。

### V0.9：直接接 DSH 的模型（不需要另外申請 API Key）

在 DSH 裡跑的時候，**預設走宿主自己的 `llm` 服務** —— 也就是你 DSH 目前選的那個模型（設定 → 模型），用的是 DSH 已經有的憑證，不用另外填 DeepSeek Key。

- **優先順序**：有填 `ai.apiKey`（或環境變數／`.env`）→ 照舊直連 OpenAI 相容 API；**沒有 Key** → 走 `ctx.llm` + `agentDefaultModel.currentSelection()` 的 provider/model。
- **兩條路都拿不到**（例如純 demo、或 profile 沒有設定模型）→ 用 JSON 台詞，遊戲照常玩。
- 啟動時 host log 會寫清楚走哪一條：
  - `AI 對話：開啟（走 DSH 的 llm 服務，不需要 API Key）`
  - `AI 對話：開啟（deepseek-chat，Key sk-…xxxx 來自 config）`
  - `AI 對話：沒有 API Key，也沒有 llm 服務，使用 JSON 台詞`
- 實作在 `src/host/ai-llm.ts`（把 DSH 的 chunk 串流 `text-delta` 接成一句話），`src/host/ai.ts` 依有沒有 Key 決定走哪條。單元測試：`test/ai-llm.test.ts`。
- **仍然安全**：瀏覽器只看得到「誰、為什麼說話」和回話文字；provider、模型、憑證都留在 host。
- 注意：模型路由要有憑證才有用。若 profile 的預設模型是 `deepseek-official` 而沒有 `DEEPSEEK_API_KEY`，log 會出現 `no API key for provider route "deepseek-official"`，並自動退回 JSON 台詞。

## 用 Tiled 改地圖

地圖在 `packs/whale-girl-pixel/maps/`，用免費的 [Tiled](https://www.mapeditor.org/) 直接打開 `room.tmj` / `garden.tmj`。規則：

- **圖層格式選 CSV**（Map → Map Properties → Tile Layer Format），不要用 Base64 / 壓縮
- **不能走的格子**：在圖塊集（`tiles.tsj`）裡給那個圖塊加 bool 屬性 `collides = true`
- **畫在角色上面**（樹冠、門框）：圖層加 bool 屬性 `above = true`，或把圖層命名為 `above`
- **物件層**放這些物件（物件的 Class/Type 欄位）：
  - `spawn`（點）：出生點，名字 `default` 必備；屬性 `face` = down / left / right / up
  - `spot`（點）：她會去的地點，名字要跟 `character.json` 的 `schedule` 對得上；屬性 `face`、`emote`、`action`（到了之後播放的動作，例如 `sit`）
  - `door`（矩形）：範圍要**包含門前那一格**；屬性 `to`（目標場景 id）、`spawn`（目標出生點）、`label`（滑鼠提示）
  - V0.2 玩法物件（矩形，蓋住的格子就是點擊範圍；她會走到**緊鄰矩形、走得到**的格子再操作）：
    - `fishing`：釣魚點；屬性 `table`（`gameplay.json` 的掉落表，預設 `pond`）、`label`
    - `plot`：一格田；名字要唯一（`plot-1`、`plot-2`…，存檔用 `場景/名字` 記住種了什麼）
    - `shop`：商人；屬性 `shop`（`gameplay.json` 的商人 id）、`label`
    - V0.4：`machine`（屬性 `machine`）、`building`（屬性 `building`，點了開動物面板）、`npc`（屬性 `npc`，那格不能穿過）、
      `mine`（礦洞入口）、`sign`（屬性 `text`、`icon`）
  - 任何門或互動物件加屬性 **`unlock` = 解鎖 id**：沒解鎖前畫 🔒、點了開解鎖面板
  - 不能點的範圍：`pen`（動物圍欄，屬性 `building`）、`area`（即時戰鬥礦洞的地面範圍）
- 地圖不能比畫面大（`scenes.json` 的 `viewport`，目前 20×12 格）；比較小的地圖會置中、四周填黑

改完跑 `npm run check:pixel`：會檢查門通不通、出生點是不是卡在牆裡、作息地點走不走得到、
玩法物件旁邊有沒有站得到的格子、掉落表和商人存不存在。

## 改玩法：`gameplay.json` 與 mods

數值和內容都在 `packs/whale-girl-pixel/` 的五個 JSON，規則程式在 `src/shared/gameplay.ts`（host 和 demo 共用）。
V0.5 把原本的單一 `gameplay.json` 拆成五個檔（V0.6 再加上 `pets.json`）（載入時組回一份，舊的單檔格式也還讀得到）：

| 檔案 | 內容 |
|---|---|
| `gameplay.json` | 主檔：下表大部分的區塊，加上 `sleep`（哪些場景能睡、幾點起床） |
| `fishing.json` | 魚、釣竿、魚餌（`gear`）、稀有度（`rarity`、`fishing.rarities`）、湖中女神（`fishing.goddess`）、掉落表 |
| `weather.json` | 天氣種類（是否澆田、`tags`、稀有加成、粒子、閃電、色調）與各季權重 |
| `animals.json` | 乾草和動物產品、建築、動物（`baby` 幼崽成長、`sellPrice` 賣價） |
| `quests.json` | 任務線：每一步的任務框文字、她說的話、催促的話、指引目標（Tiled 物件名）、完成條件、獎勵 |
| `stats.json` | V0.7 數值：體力、飽食／水分、好感的初始值、上限、流逝、動作消耗、歸零的後果、喝水、台詞（這個檔的數值優先） |
| `pets.json` | V0.6 寵物：種類、商店價格或野外出現條件與捕捉率、吃什麼、技能、貼圖；飼料和捕捉網 |

以下是 `gameplay.json` 各區塊（`fishing`、`buildings`、`animals` 實際放在各自的檔案）：

| 區塊 | 內容 |
|---|---|
| `stamina` / `satiety` / `affection` | 上限、每小時回復或衰減、每日好感上限、好感等級、喜歡與討厭的物品 |
| `items` | 物品：`id`、`name`、`emoji`、`category`（fish / crop / seed / junk）、`food`（`satiety`、`affection`；沒有就不能吃） |
| `fishing` | 體力消耗、等待時間、冷卻；`tables` 是掉落表，每筆可以限定 `phases`（時段）或 `minAffection` |
| `crops` | 作物：哪種種子、播種花多少體力、各階段的分鐘數和 emoji、收成什麼、收幾個 |
| `shops` | 商人：招呼語、交換清單（`give` 換 `get`） |
| `starter` | 新存檔送的物品（目前是空的：種子要跟商人換） |
| `calendar` | 一季幾天、有哪些季節、各季下雨機率。省略 = 沒有季節、永遠晴天 |
| `farming` | 澆一次水濕幾小時、澆水體力、沒水時的生長速度（0～1）、哪個物品是灑水器、哪些場景是溫室。省略 = 不用澆水 |
| `items` 的新欄位 | `price`（賣價）、`place`（可以擺放；`blocking`、`plot`、`where`）、`decor`（地板／壁紙換哪些圖塊）、`equip`（武器、防具、鎬子） |
| `unlocks` | 解鎖項目：名稱、費用、要先解哪個。建築的解鎖 id 要跟 `buildings` 同名 |
| `machines` | 加工機器：每個配方的材料、成品、分鐘數 |
| `collections` | 圖鑑收集：哪幾種魚、集滿給什麼 |
| `buildings` / `animals` | 建築每一級的容量和升級費用；動物的價格、產品、高級品、幾小時一次、吃什麼 |
| `npcs` | 居民：名字、emoji、喜好、台詞（可以用好感解鎖）、劇情事件、開的店 |
| `marriage` | 告白要送什麼、好感門檻、婚後幫什麼忙 |
| `mine` | 礦洞各區：樓層、時間、需要的鎬子、怪物（血量、攻擊、掉落）、礦物掉落 |
| `calendar.festivals` | 節慶：哪一季第幾天；交換可以寫 `festival` 只在當天出現，掉落表也可以 |

掉落表的每一筆除了 `phases`、`minAffection`，還可以寫 `seasons`、`weather`（`sunny` / `rainy`）；作物可以寫 `seasons`。
商人加 `"verb": "製作"` 就變成加工台（料理台就是這樣做的），在 Tiled 放一個 `shop` 物件指到它即可。

**不想改原檔，就放 mod**：在 host 的存檔目錄建 `mods/`，放任意 `*.json`（依檔名排序合併）。
`items`、`crops`、`collections`、`festivals` 以 `id` 覆蓋或新增；`unlocks`、`machines`、`buildings`、`animals`、`npcs` 以 key 覆蓋或新增；
`calendar` 整個換掉；掉落表和商人的交換清單是**附加**；V0.5 的 `questChains`、`weatherTypes` 以 `id` 覆蓋或新增，`weatherSeasons` 整季覆蓋；V0.6 的 `petSpecies` 以 key 覆蓋或新增；格式錯的 mod 會被跳過並在 log 警告。
拿掉 mod 後，揹包裡認不得的物品會保留在存檔裡，只是不顯示，不會壞檔。

```json
{ "id": "lobster-pack",
  "items": [{ "id": "fish_lobster", "name": "龍蝦", "emoji": "🦞", "category": "fish", "food": { "satiety": 30, "affection": 6 } }],
  "fishing": { "tables": { "pond": [{ "item": "fish_lobster", "weight": 3, "phases": ["night"] }] } } }
```

### 台詞條件（`character.json` 的 `lines`）

| 欄位 | 用途 |
|---|---|
| `on` | 什麼時候說：`click`（預設）、`enter`、`welcome`，V0.2 新增 `feed`、`full`、`levelup`、`tired`、`caught`、`harvest`、`no_seed`，V0.4 新增 `festival`、`married`、`mine_go`、`mine_back`、`help` |
| `items` / `categories` / `tags` | 只對某些物品、分類、標籤說；標籤有 `liked`、`disliked`、`capped`（今天好感已滿） |
| `minAffection` | **好感到多少才解鎖**；沒到就不會出現 |
| `action` | 說這句時播放的動作 |

越具體的台詞越優先（指定物品 > 標籤 > 分類），所以餵河豚會說河豚專屬的那句。
`levelup` 台詞裡的 `{level}` 會換成新的等級名稱。

## 換成你的角色

1. 複製 `packs/whale-girl-pixel/` → `packs/my-cat/`
2. 換走路圖（最簡單的做法）：準備一張**白底、4 列 × 4 欄**的角色圖（PNG 或 JPG），格子之間留白
   - 列由上到下：正面、面向左、面向右、背面；欄：站立、走路 A、走路 B、站立 2
   - AI 生成的也可以，用內附工具轉換（需要 Python 3、`pip install pillow numpy`）：
     ```sh
     python3 tools/import_sheet.py 原圖.png packs/my-cat/assets/whale-girl-world.png --preview 預覽.png
     ```
     工具會切格、去白底（包含頭髮和尾巴之間的白色縫隙，衣服的白色會保留）、對齊腳底和頭部、縮小，
     最後印出要貼進 `character.json` 的 `world` 設定
   - `--height`：角色圖本身的像素高度（預設 120）；`--display`：在地圖上顯示幾個地圖像素高（預設 40，約 2.5 格）。
     兩者的比例就是 `drawScale`，預設 1/3：在最常見的 3 倍放大下剛好一對一，最清楚
3. 動作表（可省略）：停下來、說話、到定點時播放的**正面**動作，每一列是一段動作，第一格放普通站姿
   ```sh
   python3 tools/import_sheet.py 動作表.png packs/my-cat/assets/whale-girl-actions.png --grid 5x6 --mode actions --ref-height 118
   ```
   `--ref-height` 填轉走路圖時印出的站姿身高，兩張圖的大小才會一致。轉完把印出的設定貼進 `character.json` 的 `actions`，
   再把 `clips` 改成有意義的名字：
   ```jsonc
   "clips": {
     "wave":   { "row": 0, "frames": [0, 1, 2, 3, 4, 3, 4, 5], "fps": 6 },          // 播一次就回到站姿
     "sit":    { "row": 1, "frames": [0, 0, 5, 0, 4, 4, 0, 1], "fps": 2, "loop": 0 }, // loop：一直重複，直到她起身走路
     "sleepy": { "row": 3, "frames": [0, 1, 1, 2, 3], "fps": 2, "loop": 3 }           // 從第 3 個開始重複（打瞌睡 ⇄ zzz）
   }
   ```
   用在哪裡：`actions.onClick`（點她時的預設動作）、台詞的 `"action"`、Tiled 地點的 `action` 屬性
4. 其他圖：
   - **對話框頭像**（`portrait`）：任意插畫，可以是水平 sprite sheet（填 `frames`、`fps`）
   - **表情**（`emotes`）：16×16 一格、水平排列，`names` 依序命名
   - **圖塊**：`assets/tiles.png` 每格 16×16，換掉後在 Tiled 重新設定碰撞屬性
   - 也可以手點真正的像素圖：每格 16×32、`drawScale` 設 1（或省略），可以多一欄眨眼（`blink`）
5. 改作息與台詞：`character.json` 的 `schedule`、`lines`
6. 檢查：`npm run check:pixel -- my-cat`（動作名稱寫錯、loop 超出範圍都會抓到）
7. 看效果：`http://localhost:8080/demo/pixel.html?pack=my-cat`

## 架構只有一條規則

**Host 是唯一真相，前端只透過 `HostBridge` 讀寫。**
釣到什麼、作物熟了沒、好感加多少，全部由 host 用 `bridge.act({ type: 'fish' | 'plant' | 'harvest' | 'feed' | 'trade', … })` 決定並存檔；
畫面只負責走過去、播表情、顯示結果。所以重新整理不能刷魚，之後接多人也不用改規則。
時間是「看時間戳記補算」（lazy tick）：關掉一整天再打開，體力、飽食、作物生長都會一次算好（最多補 72 小時）。
存檔從 V0.1 的 `version: 1` 自動升級。她在地圖上的位置不存檔，每次從出生點或作息地點開始。

## 像素畫面的幾個細節

- **角色比地圖細緻**：地圖是 16 像素一格，角色圖的 1 像素只佔地圖的 1/3 像素（`drawScale`），臉和頭飾才看得清楚。
  畫面放大倍率剛好是 3 倍時一對一最銳利，其他倍率會平滑縮放
- **整數倍放大**：依螢幕縮放比例（`devicePixelRatio`）算出整數倍數。Windows 開 125% / 150% 縮放時，畫面可能比容器小一點、兩側留黑邊，換來每個像素一樣大、不會一格寬一格窄
- **說話時她會停下來**；角色在畫面下半部時，對話框改放上方，才不會擋住她
- **輪詢用 `visit()`**：畫面開著就代表主人在，順便更新「上次見面」時間；畫面藏起來時不輪詢

1. `Schema` 從哪個套件匯出（`src/host/index.ts`）
2. 內建 `storage` 服務有沒有提供插件專屬目錄；沒有才沿用 `~/.dsh/storages/dsh-whale-pet/`（`src/host/service.ts`）
3. **宿主 ↔ 瀏覽器通道**：`src/host/index.ts` 目前假設有 `ctx.server.post(...)`（Koa 風格），前端用 `fetchTransport('/api/dsh-whale-pet')`。
   如果 DSH 用 @Remote 方法，把 `handleBridgeCall`（`src/host/routes.ts`）包成 Remote 方法即可，規則和參數檢查不用改
4. **tool 註冊**：`index.ts` 假設 `ctx.tools.register(def)`，def 是 `{ name, description, parameters（JSON Schema）, handler }`。
   兩個 tool：`whale_pet_status`（唯讀摘要）、`whale_pet_act`（只開放餵食、澆水、收成）
5. 槽位名稱與 `slots` API 形狀；`package.json` 裡 `dsh.client.inject` 的服務名（舊的 `dsh-client-runtime` 在新版宿主已移除）
6. `cordis.patch.yml` 格式
7. `engines.dsh` 範圍要涵蓋你實際測過的版本
8. 打包：本專案用 esbuild（`npm run build`）；社群多用 tsdown，兩者擇一即可
9. 像素畫面至少要 320px 寬才能 1 倍顯示；DSH 浮層建議給 640px（2 倍）

本機掛載測試：`dsh plugin --profile <你的開發 profile> add link:<本專案路徑>`。
裝好 `@deepseek-ai/*` 之後，把 `host/index.ts`、`host/service.ts`、`client/dsh-entry.tsx` 加進 `tsconfig.json` 的 `include`。
