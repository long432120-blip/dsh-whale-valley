# V0.24 設計書：DSH 左側欄入口（取代浮層啟動卡）

> ⚠️ **這一版的「🪟 開新視窗玩」在 DSH 桌面版其實按不出東西**（Electron 的 `setWindowOpenHandler` 會 deny `window.open`）。
> **V0.25 已經改成「點側欄＝用系統瀏覽器開獨立視窗」**，請看 [`V0.25-設計書.md`](V0.25-設計書.md)；下面留著當歷史。

這一版只改 DSH 的進入方式，**沒有改玩法、存檔、host 行為**。

- 版本：`0.24.0`（套件檔 `release/dsh-whale-valley-0.24.0.tgz`）
- 單機試玩版不受影響（`demo/pixel-standalone.html` 的內容沒有變，朋友那包還是 v0.23）

---

## 1. 為什麼改

| 版本 | DSH 的進入方式 | 問題 |
|---|---|---|
| V0.22 | 常駐浮層，整個遊戲長在 DSH 畫面上 | 擋住 DSH 自己的畫面 |
| V0.23 | 浮層只放一張小卡片（`shell.overlay`），按「▶ 啟動遊戲」或「🪟 開新視窗玩」 | 卡片還是浮在 DSH 的內容上面；而且 `shell.overlay` 是「Frame-wide floating layer」，不佔版面 |
| **V0.24** | **左側欄多一個「鯨魚谷物語」入口**，點下去中央欄顯示啟動卡 | 跟「插件／自動化任務／上下文洞察」同一個層級，不再蓋住任何東西 |

DSH 的左側欄有兩個槽位（用 `cordis_inspect_query` 查 `Slots` 得到）：

| 槽位 | 種類 | 用途 |
|---|---|---|
| `sidebar.panellist` | list | 全局面板圖示；**每個 list id 對到同名的 `main` 面板**（側欄自己畫按鈕、自己處理選取） |
| `main` | keyed | 中央面板，key 就是側欄的 id（官方保留的 `conversation` 是對話） |

所以「左側欄入口」= 兩邊各註冊一次，id/key 用同一個字串。

## 2. 改了哪些檔案

| 檔案 | 改動 |
|---|---|
| `src/client/dsh-entry.tsx` | 不再註冊 `shell.overlay`；改成註冊 `sidebar.panellist`（`id: 'whale-valley'`, `order: 30`）＋ `main`（`key: 'whale-valley'`）。新增 `WhaleIcon`（左側欄圖示）與 `WhaleValleyPanel`（中央面板）。 |
| `src/client/launcher.ts` | `LauncherOptions` 多了 `variant?: 'card' \| 'panel'`（預設 `'card'`，行為跟 V0.23 一樣）；`'panel'` 時卡片放大：寬度 `min(560px, 100%)`、標題 22px、按鈕 `12px 22px`。 |
| `locales/zh-TW.json`、`locales/zh-CN.json` | 新增 `launch.label`（「鯨魚谷物語」／「鲸鱼谷物语」）。左側欄已經有鯨魚圖示，label 不再帶 🐋。 |
| `package.json` | `0.23.0` → `0.24.0` |
| `lib/client.js`、`lib/index.js` | 重新打包（`lib/index.js` 內容沒變） |

沒有改：`src/host/**`、`src/shared/**`、`packs/**`、任何遊戲規則或存檔欄位。

## 3. 程式長什麼樣

```tsx
const PANEL_ID = 'whale-valley';   // 左側欄 id ＝ main 的 key

// 左側欄圖示：DSH 傳 { size, active }，線條用 currentColor 跟著主題
function WhaleIcon(props: { size?: number; active?: boolean }) { … <svg stroke="currentColor"> … }

// 中央面板：置中一張啟動卡（遊戲本身還是不長在 DSH 版面裡）
function WhaleValleyPanel() {
  const ref = useRef<HTMLDivElement>(null);
  useEffect(() => mountDshLauncher(ref.current!, 'panel'), []);
  return <div className="whale-panel" style={{ display:'flex', alignItems:'center', justifyContent:'center',
                                              width:'100%', minHeight:'100%', padding:'24px 16px', boxSizing:'border-box', overflow:'auto' }}>
           <div ref={ref} style={{ width:'100%', maxWidth:'560px' }} />
         </div>;
}

export function apply(ctx) {
  const slots = ctx.slots;
  slots.inject('main', () => slots.register({ name: 'main', key: PANEL_ID }, WhaleValleyPanel));
  slots.inject('sidebar.panellist', () =>
    slots.register({ name: 'sidebar.panellist', id: PANEL_ID, order: 30, label: () => t('launch.label') },
                   (props) => <WhaleIcon size={props.size} active={props.active} />));
}
```

- `slots.inject(...)` 一樣先等槽位被宣告再 `register`（跟 V0.22 的寫法相同），DSH 收起槽位時會自動卸載。
- `label` 傳的是函式：切換繁簡時 DSH 會重讀，不用重新註冊。
- 圖示全部是 inline SVG，**沒有新增任何外部檔案或請求**（`npm run check:offline` 照樣通過）。

## 4. 兩種玩法照舊

啟動卡上的兩顆按鈕跟 V0.23 完全一樣：

- **▶ 啟動遊戲**：在 `<body>` 最後面蓋一層 `.whale-fs-layer`（fixed、z-index 9999、100vw×100vh），右上「❌ 關閉遊戲」；打開時記下 `<html>` 的 `overflow`，關閉時還原。
- **🪟 開新視窗玩**：`window.open('/api/dsh-whale-valley/play', 'WhaleValley', 'width=1280,height=720,…')`，跟 DSH 同一份存檔（host 的通道）。

兩個模式都在「中央面板」之外，所以切到別的側欄分頁（例如回去對話）不會把遊戲畫面切掉。

## 6. 安裝注意

- 一定要用套件檔安裝：`dsh plugin --profile <profile> add ./dsh-whale-valley-0.24.0.tgz`（或 `github:`／GitHub tar.gz）。**不要用本機資料夾（link）**，原因見 README。
- 從 0.23.0 升上來：直接 `add` 新的 tgz 即可（`remove` 再 `add` 也可以）；存檔在 `~/.dsh/storages/dsh-whale-valley`，不會動到。
- 想回到 V0.23 的浮層卡片：`apply()` 把 `main` / `sidebar.panellist` 兩段換回 `shell.overlay` 的註冊即可，`launcher.ts` 不用改（預設還是 `variant: 'card'`）。
