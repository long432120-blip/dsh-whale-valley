# V0.10 設計書：換上 GPT 畫的素材表

把擁有者用 GPT 畫的素材表（`assets/source/gpt-asset-sheet.png`，1536×1024，純綠背景）切開，換進遊戲：地面、建築、樹、灌木、柵欄、動物、作物、物品圖示。

**原則：有圖用圖，沒有就照舊用 emoji。** 素材表只涵蓋一部分東西，沒對到的不會壞，會繼續顯示原本的樣子。

---

## 1. 流程

```
gpt-asset-sheet.png
   │  python3 tools/import_asset_sheet.py
   │    1. 偵測：綠背景上的每個物件 → 外框，依位置編號（--labels 會輸出標了編號的圖）
   │    2. 去背：看「跟背景純綠差多遠」決定透明度（植物的深綠不會被去掉），邊緣去溢色
   │    3. 依對照表（檔案開頭的 SHEET_*）放到對的地方
   ▼
assets/tiles-hd.webp   高解析圖塊：跟 tiles.png 同排列，每格 64px（4 倍）；沒換到的格子是舊圖放大
assets/sprites.webp    圖集：動物、作物、物品圖示
sprites.json           圖集座標＋「哪個物品／動物／作物用哪張」
```

**換新的素材表：**

1. 覆蓋 `gpt-asset-sheet.png`。
2. 跑 `python3 tools/import_asset_sheet.py --labels`，看 `gpt-asset-sheet-labels.png` 的編號。
3. 改 `tools/import_asset_sheet.py` 開頭的對照表。
4. 再跑一次 `python3 tools/import_asset_sheet.py`（不加 `--labels`）。
5. 跑 `npx tsx scripts/check-pixel.ts`，它會檢查 `sprites.json` 對到的物品、作物、動物是否存在，以及作物的階段數。

## 2. 地面、建築、樹

| 圖塊 | 素材 |
|---|---|
| `grass0`／`grass1`／`grass2` | 草地（`grass1` 是轉 180° 的同一張，避免重複感）、有小花的草地 |
| `path0`／`path1` | 泥土路 |
| `sand0`／`sand1` | 沙灘 |
| `pave0`／`pave1` | 石板路（小鎮） |
| `floor0`／`floor1`、`gh_floor` | 木地板（閣樓、溫室） |
| `soil` | 翻好的田 |
| `water`、`lily` | 水面、荷葉 |
| `w_*`、`ws_*`（水邊） | 用舊圖塊「哪些像素是水」當遮罩，新的水＋新的草地／沙灘合成，交界畫一圈泥土色的岸和淡淡的浪花 |
| `bush`、`fence`、`rock` | 開花灌木、木柵欄、石頭（去背；灌木和柵欄墊草地） |

**建築和樹**：程式先在地圖裡找出每棟建築佔的格子範圍（例如牛棚 4×3），再把整張圖等比縮放進那個範圍（貼底置中），最後切成一格一格。**地圖不用改**。

| 地方 | 建築 |
|---|---|
| 花園 | 鯨魚娘的家（紅屋頂）、旅行商人攤位、大樹 |
| 牧場 | 牛棚（紅色穀倉）、溫室、馬廄、雞舍 ⚠ |
| 小鎮 | 花店、鐵匠鋪 |
| 海邊 | 老陳的小屋（藍屋頂） |

⚠ **素材表沒有雞舍**，先借用藍屋頂小屋（跟海邊的小屋同一張）。請 GPT 補畫一間雞舍之後，改 `SHEET_GROUPS['coop']` 就好。

**去掉格線**：

- GPT 畫的圖塊四邊有一圈框線，直接拼起來會看到格線。程式會把每格跟「平移半格的自己」交叉淡化，讓圖塊可以無縫拼接。
- 高解析圖塊用**無損** WebP。有損壓縮會在相鄰格子之間滲色，拼起來一樣看得到細線。

### 高解析繪製

`renderLayers()` 看到 `sprites.json` 的 `tilesHd`（而且尺寸剛好是 `tiles.png` 的 4 倍），就用 64px 的格子畫圖層。貼到畫面時，`blitLayer()` 會照目前的放大倍率先縮一次存起來（高品質縮圖），之後每一幀直接貼上。做法跟 V0.9 的房間背景圖一樣，所以：

- 螢幕上看到的是原圖的細節，不是 16px 放大的馬賽克；
- 沒有 `tiles-hd` 時，照舊用 16px 圖塊，什麼都不會壞。

## 3. 動物、作物、物品

| 類別 | 有圖的 | 沒圖（用 emoji） |
|---|---|---|
| 動物（成年＋幼崽） | 雞、鴨、牛、羊、豬 | — |
| 作物 | 胡蘿蔔、草莓、番茄、南瓜：每個生長階段；辣椒、白菜：發芽用通用的芽 | 辣椒、白菜的成熟階段 |
| 物品圖示（43 種） | 4 種作物、蛋、牛奶、羊毛、起司、果醬、美乃滋、醃蘿蔔、燻魚、鱸魚／鯖魚／鱒魚、種子袋、寵物飼料、釣竿、魚餌球、鎬子、漂流木、銅礦、鐵礦、銅錠、金錠、石英、野莓、野花 | 其他 76 種（大部分的魚、裝備、家具、寶石…） |

```ts
// src/shared/sprites.ts
itemFrame(file, itemId)            // 有圖 → 座標；沒有 → null
animalFrame(file, kind, baby)      // 幼崽沒圖 → 用成年
cropFrame(file, cropId, stage)     // 圖 → 座標；null → 不畫（剛播種只看得到田）；undefined → 用 emoji
```

| 畫在哪 | 怎麼畫 |
|---|---|
| 地圖上的作物、動物、擺放的家具、地上的掉落物 | canvas：`spriteAt()` 從圖集切一塊、平滑縮圖；動物往右走時翻過來；幼崽畫小一點 |
| 揹包、魚類圖鑑、送禮 | DOM：`slotIcon()`，用 CSS 背景切圖集的一塊。圖集網址只設一次在 `.px-app` 的 `--px-atlas`（打包版是 data URL，每格都寫一次太大） |

商店、對話裡夾在文字中的 emoji（例如「🥕 胡蘿蔔 ×2」）沒有換，因為那些是一整段文字。

## 4. 其他

- **提示框不超出畫面**：DSH 回報畫面 280px 寬時，滑鼠提示框左邊會超出畫面 23px。現在 `placeTip()` 會把提示框的中心夾在畫面範圍內，太長的字會用「…」截斷。實測 280px 寬時，左邊從 −23px 變成 10px。
- **檔案大小**：
  - `tiles-hd.webp` 644 KB（無損），`sprites.webp` 138 KB。
  - 雙擊版 `pixel-standalone.html` 從 2.3 MB 變 3.1 MB。
  - DSH 的 `lib/client.js` 從 2.5 MB 變 3.3 MB。
