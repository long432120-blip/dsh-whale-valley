## 2. 鯨魚娘的像素日記

每天睡覺時，她把今天發生的事寫成一篇 50 字以內的日記。早上起床先翻開給主人看，收好才說早安。

### 2.1 流程

```
白天：每個成功的動作 → logEvent → 存檔的 dayLog
   釣魚、種菜、收成、餵食、送禮、礦洞、酒館、泡澡、零食、冰箱、撿東西、動物、家具、賣東西……
       │
睡覺（sleep）
       │ 規則層（host、demo 共用，同步、不碰網路）
       ▼
  dayFacts(dayLog)   → ["第一次釣到鯉魚", "釣到3條魚，有鱸魚", "種了2顆胡蘿蔔", …]（照重要程度排）
  templateDiary(...) → 用 diary.json 的句子拼一篇（一定有，≤ 50 字）
  存成一篇日記 { id, date, weather, facts, text, source: 'template', read: false }
  dayLog 歸零；事件 slept 帶回 diary: id
       │
       │ DSH 的 host（service.act）
       ▼
  AI 能用（有 API Key，或 DSH 的 llm 服務）→ 這篇標記 pending（正在寫）→ 背景呼叫 DeepSeek
       ├─ 成功：換成 AI 寫的（source: 'ai'），pending 拿掉
       └─ 失敗、逾時、沒額度：pending 拿掉，留著拼的那篇
       │
畫面
  起床 → 日記本翻開。pending 時顯示「✏️ 她正在寫日記……」，每 1.5 秒問一次 host
  → 寫好了就一個字一個字寫出來
  → 「📔 收好日記」標記已讀（diary_read）→ 她說早安
```

### 2.2 只有 host 會叫 AI

- **Key 的位置**：API Key 只在 host（DSH 插件設定、環境變數、`.env`）。瀏覽器不能送日記內容，規則層也沒有「寫入日記文字」這種動作。
- **送出去的內容**：只有 4 樣——日期、天氣、今天的事（紀錄整理成的一行行中文）、和主人的關係。不送整個存檔。
- **Prompt**：
  - system：鯨魚娘的角色設定（`ai.json` 的 `personas.whale`）＋寫日記的規則（`ai.json` 的 `diary.rules`）
  - user：今天的紀錄＋「主人睡著了。請寫今天的日記。」
- **回覆整理**：
  - 去掉引號、Markdown、開頭的「鯨魚娘：」
  - 超過 50 字在標點斷句，不然截斷加「…」
- **demo、單機版**：沒有 host，用拼出來的那篇；畫面一樣。
- **失敗紀錄**：寫在存檔資料夾的 `ai-error.log`（不含 Key）。

### 2.3 一直在「寫」怎麼辦

`pending` 只在 `pendingSince`（host 時鐘）之後 2 分鐘內有效。超過 2 分鐘，或 host 在寫的時候重開，讀存檔時就當作沒在寫，留拼的那篇。畫面最多問 40 次（約一分鐘）。

### 2.4 資料

**`diary.json`**（新的玩法分檔，host、單機版、角色包讀取都已接上）：

```jsonc
{
  "maxChars": 50, "keep": 60,
  "facts": { "fish": "釣到{n}條魚，有{item}", "planted": "種了{n}顆{item}", "fed": "主人餵我吃了{item}", ... },
  "weather": { "sunny": "天氣很好。", "rainy": "下雨了。", "storm": "打雷了，好可怕。" },
  "openers": ["今天{weather}", "{weather}"],
  "closers": ["好開心～", "明天也要跟主人一起！", "噗嚕～好睏，晚安。", "最喜歡主人了。"],
  "empty": ["今天黏在主人身邊發呆，也很好～", ...]
}
```

- **今天的事（22 種）**：照下面的順序挑最重要的：
  - 結婚 → 傳說的魚 → 第一次釣到的魚 → 關係升級 → 抓到寵物
  - → 釣魚 → 收成 → 種菜 → 餵食 → 送禮 → 礦洞 → 酒館贏 → 玩遊戲 → 泡澡 → 零食 → 冰箱 → 撿東西 → 動物 → 家具 → 賣東西 → 澆水 → 聊天
- **`{item}`**：那件事最常出現的東西，例如釣最多的魚。
- **拼的規則**：開頭（天氣）＋最重要的兩件事＋結尾。超過字數就依序：
  1. 拿掉第二件事
  2. 再拿掉結尾
  3. 還是太長就截斷

**`ai.json` 的 `diary`**：`maxChars`、`temperature`、`maxTokens`、`rules`（寫日記的規則）、`request`（最後一句）。

### 2.5 存檔與 host 動作

| 欄位／動作 | 說明 |
|---|---|
| `game.dayLog` | `{ since, counts, items }`：上次起床到現在的紀錄 |
| `game.diary` | 日記，舊的在前面，最多留 `keep` 篇 |
| `slept` 事件 | 多了 `diary`：這次寫的日記 id |
| `{ type: 'diary_read', id }` | 看過了（不再自動翻開、📔 的小紅點消失） |
| `view.game.diary` | `{ entries（新的在前面）, unread, today（今天記了幾件事） }` |
| `service.writeDiaryWithAi` | host 背景請 AI 寫；只有 host 能換掉日記文字 |
| tool `whale_pet_status` | 多一行「最近的日記」 |

### 2.6 畫面

- **📔 按鈕**：在側邊欄，鍵盤 L 也能開。有沒看過的日記時亮小紅點。
- **日記本**：像素木頭封面、線圈、橫線紙、紅色邊線，日期和天氣在上面。
  - 內文用楷體，一個字一個字寫出來。
  - 下面簽名「—— 鯨魚娘」，AI 寫的多一個 ✨。
  - 再下面是便利貼「📌 今天的紀錄」。
  - 可以翻前一天、後一天。
- **自動翻開**：
  - 起床的時候。
  - 打開畫面時有還沒看的日記，例如用 tool 讓她睡、或在別台電腦睡的：等對話和其他視窗關掉才翻開。
