## 1. 循環總覽

```
            釣魚 -10、種田 -2、澆水 -2、下礦 -30
   ⚡ 體力 ────────────────────────────────▶ 0：這些動作都被拒絕（她會說怎麼恢復）
      ▲  ▲
      │  └── 吃東西：+ 飽食度的一半（物品可以自己寫）
      └───── 睡覺（快轉到隔天 6 點）或現實時間過了早上：補滿

            每小時 -4（睡覺那段只掉一半）
   🍙 飽食／水分 ──────────────────────────▶ 0：體力上限減半；每過一個早上好感 -5
      ▲  ▲
      │  └── 吃東西：+ 食物的飽食度
      └───── 在池塘、河邊喝水：+20（每 10 分鐘一次）

   ❤ 好感：餵食、摸頭、聊天會增加；只有「餓著過夜」會下降
```

壓力的來源是「體力只有 100、不會自己回」和「飽食度一天多一點就會見底」。但出路都很便宜：喝水免費、睡覺免費、釣到的魚可以直接吃，所以不會卡死。

## 2. `stats.json`

```json
{
  "version": 1,
  "lowRatio": 0.3,
  "stamina": { "start": 100, "max": 100, "regenPerHour": 0, "restoreOnMorning": true },
  "satiety": {
    "start": 80, "max": 100, "decayPerHour": 4, "sleepDecayMult": 0.5,
    "whenEmpty": { "staminaMaxMult": 0.5, "affectionLossPerDay": 5 },
    "drink": { "tables": ["pond", "river", "fishpond"], "satiety": 20, "cooldownMinutes": 10 }
  },
  "affection": { "start": 0, "decayPerHour": 0 },
  "actions": { "fish": { "stamina": 10 }, "plant": { "stamina": 2 }, "water": { "stamina": 2 }, "mine": { "stamina": 30 } },
  "eat": { "staminaPerSatiety": 0.5 },
  "lines": {
    "tired": ["好累，想睡覺……", "…"],
    "exhausted": ["不行了……一點力氣都沒有。讓我吃點東西，或回房間睡覺嘛。", "…"],
    "hungry": ["咕嚕……肚子餓了。", "好渴喔……可以去池塘喝口水嗎？"],
    "starving": ["…"], "drink": ["…"], "ate": ["…"], "rested": ["…"]
  }
}
```

| 欄位 | 意思 |
|---|---|
| `lowRatio` | 低於上限的這個比例，進度條變紅閃爍、她會提醒 |
| `stamina.regenPerHour` | 每小時自然恢復。設成 0 表示只靠睡覺和吃東西；想輕鬆一點可以改成 3～5 |
| `stamina.restoreOnMorning` | 過了起床時間（睡覺快轉，或現實時間過夜）就補滿 |
| `satiety.sleepDecayMult` | 睡覺快轉那段時間，飽食度流逝的倍率 |
| `satiety.whenEmpty` | 歸零時的體力上限倍率、每過一個早上扣多少好感 |
| `satiety.drink.tables` | 哪些水域能喝（用釣魚的水域 id；海水不能喝） |
| `actions.*.stamina` | 每種動作消耗的體力 |
| `eat.staminaPerSatiety` | 吃東西恢復的體力 = 食物的飽食度 × 這個值。個別物品可以在 `food.stamina` 寫固定值 |

`stats.json` 是唯一的來源：載入時 `applyStats` 會把它寫回 `gameplay.json`、`fishing.json` 裡原本的欄位（體力上限、飽食度流逝、釣魚／澆水／種田／礦洞的體力消耗），所以舊欄位留著也不會衝突。

## 3. 數值更新（定時扣除、動作扣除）

```ts
staminaCap(satiety) = satiety <= 0 ? floor(stamina.max × whenEmpty.staminaMaxMult) : stamina.max

// 定時扣除：每次有動作、每次畫面刷新、離線回來，都先把時間結算到現在
tickGame(g, now, { satietyMult = 1 }):
  hours   = (now - g.lastTickAt) / 1 小時
  decay   = satiety.decayPerHour × satietyMult
  satiety = max(0, g.satiety - hours × decay)

  affection = max(0, g.affection - hours × affection.decayPerHour)
  for t in 這段時間經過的每個早上（起床時間）:
      if g.satiety - (t - lastTickAt) × decay <= 0:        // 那個早上是餓著的
          affection = max(0, affection - whenEmpty.affectionLossPerDay)

  cap     = staminaCap(satiety)
  stamina = min(cap, g.stamina + hours × stamina.regenPerHour)   // 餓到歸零時，超過上限的部分被壓掉
  if 經過了至少一個早上 and restoreOnMorning: stamina = cap     // 睡飽了

// 動作扣除：每個動作先結算時間，再檢查體力
applyAction(g, action, now):
  g = tickGame(g, now)
  cost = actions[action.type].stamina          // fish 10、plant 2、water 2、mine 30
  if g.stamina < cost: return 失敗 'no_stamina'
  執行動作；g.stamina -= cost

// 畫面
view.staminaMax       = staminaCap(g.satiety)                       // 餓著時顯示成「50/50」
view.stats.low        = { stamina: g.stamina < max × lowRatio, satiety: g.satiety < max × lowRatio }
view.stats.starving   = g.satiety <= 0
view.stats.costs      = { fish, plant, water, mine }
```

體力歸零時：
- host 回 `no_stamina`，所以釣魚、種田、澆水、下礦都做不了。
- 畫面上她會說一句 `lines.exhausted`，旁邊提示「⚡ 體力不夠：吃東西，或回房間睡覺」。
- 池塘選單裡的「🎣 釣魚」會變灰，寫「體力不夠」。

## 4. 吃東西、喝水

```ts
run('feed', item):
  food = items[item].food；沒有 → 'not_food'；揹包沒有 → 'no_item'
  satAfter = min(satiety.max, g.satiety + food.satiety)
  stGain   = food.stamina ?? round(food.satiety × eat.staminaPerSatiety)
  stAfter  = max(g.stamina, min(staminaCap(satAfter), g.stamina + stGain))   // 先算吃完後的上限
  if g.satiety 已滿 and stAfter <= g.stamina: return 失敗 'full'              // 兩個都滿才吃不下
  好感 += food.affection ×（喜歡 2、討厭 0），受每日上限限制（原本的規則）
  揹包 -1；satiety = satAfter；stamina = stAfter
  event fed { satiety: 加了多少, stamina: 加了多少, gain: 好感 }

run('drink', table):
  table 不在 drink.tables → 'unknown'（例如海水）
  g.satiety 已滿 → 'full'；距離上次喝水不到 cooldownMinutes → 'cooldown'
  satiety = min(max, g.satiety + drink.satiety)；lastDrinkAt = now
  event drank { satiety }
```

畫面：
- **揹包**：點魚、作物、料理會先選起來，下面出現一列「🐟 鱸魚　🍙 +25　⚡ +13　❤ +3　[🍴 餵她吃]」。兩個數值都滿了，按鈕變灰寫「她吃不下了」。
- **池塘**：她的飽食／水分不到八成、而且這裡的水能喝時，點水邊會先問「🎣 釣魚（⚡ -10）／💧 喝水（🍙 +20）／👋 離開」；她不渴就跟以前一樣直接釣魚。喝水還在冷卻時，選項變灰寫「再等 N 分鐘」。

## 5. 跟「快轉時間」的結合

三種「時間往前跳」走的都是同一個 `tickGame`，所以結果一致：

| 方式 | 做了什麼 | 體力 | 飽食／水分 |
|---|---|---|---|
| 睡覺（房間的床） | `clockOffset` 加到隔天 6 點，`tickGame(…, { satietyMult: sleepDecayMult })` | 補滿（餓到歸零的話只補到一半） | 這段時間只掉一半 |
| demo 的「⏩ 快轉 3 小時」「⏭ 跳到明天」 | 把存檔的時間往回撥，等於過了那麼久 | 沒過早上就不變；過了早上補滿 | 照每小時 -4 掉 |
| 真的過了一段時間（關掉再回來） | 下次打開時結算 | 同上 | 同上 |

```ts
run('sleep'):
  to   = 下一個起床時間
  woke = tickGame({ ...g, clockOffset: g.clockOffset + (to - now) }, to, { satietyMult: satiety.sleepDecayMult })
         // 作物、動物、下雨澆田、寵物、烏鴉照常結算；經過了一個早上 → 餓著的話好感 -5
  woke.stamina = staminaCap(woke.satiety)
```

## 6. UI 反饋

- **進度條**：體力、飽食／水分低於 30% 時，那一條變紅並閃爍，數字和圖示也變紅。系統設定「減少動態效果」時不閃，只變紅。
- **好感條**：只有在她餓到歸零（好感正在下降）時變紅。新存檔的好感本來就是 0，如果照「低於 30% 就紅」，一開始就會一直是紅的，所以這一條沒有照字面做。
- **台詞**：數值剛掉到 30% 以下、或剛歸零時，她頭上會冒一句（`hungry`、`tired`、`starving`）；之後還是很低的話，每 3 分鐘最多再提醒一次。
- **滑鼠移到進度條上**：會寫現在的狀態和怎麼恢復。
