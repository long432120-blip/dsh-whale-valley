# V0.14 設計書：家具目錄（購買、二手賣出、多格擺放）＋背景音樂

這一版做兩件事：
- **家具目錄**：照擁有者的五點需求實作，讓玩家有辦法買到家具。
- **背景音樂**：擁有者放在 `開發/` 的五首音樂，照檔名放到對應的地方。

---

## 1. 家具目錄

### 1-1 資料：`packs/whale-girl-pixel/furniture_shop.json`

```jsonc
{
  "version": 1,
  "name": "小葵的家具目錄", "emoji": "🪑",
  "npc": "florist",                  // 小葵的選單裡會多一個「看家具目錄」
  "resaleRate": 0.5,                 // 二手賣出 = 買價 × 50%
  "categories": { "furniture": "一般家具", "deco": "小擺飾", "rug": "地毯", "outdoor": "戶外", "floor": "地板", "wall": "壁紙" },
  "items": [
    { "id": "furn_bed_double", "name": "雙人床", "price": 800, "emoji": "🛏️", "size": {"w": 2, "h": 2}, "category": "furniture", "where": "indoor" },
    { "id": "furn_rug_blue",   "name": "藍色地毯", "price": 250, "emoji": "🟦", "size": {"w": 2, "h": 2}, "category": "rug", "rug": true },
    { "id": "floor_blue",      "name": "藍色地板", "price": 300, "emoji": "🟦", "category": "floor" },
    …
  ]
}
```

| 欄位 | 說明 |
|---|---|
| `id` | 物品 id（小寫英文、數字、底線） |
| `name`、`emoji` | 名稱、圖示（素材表有圖時畫圖，沒有就用 emoji） |
| `price` | 買價（金幣） |
| `size` | 佔幾格 `{w, h}`，左上角是擺放的位置；沒寫 = 1×1。地板、壁紙不用寫 |
| `category` | 分類，要在 `categories` 裡；`floor`、`wall` 是換整面地板／壁紙 |
| `where` | `indoor`、`outdoor`、`any`（預設 any） |
| `blocking` | 擋不擋路（預設擋；地毯預設不擋） |
| `rug` | 地毯：不擋路，上面還能再擺一件家具 |
| `description` | 說明文字 |
| `decor` | 新的地板／壁紙要換哪些圖塊（舊的可以不寫） |

**跟 `gameplay.json` 的關係**：載入時（`gameplay-pack.ts` 的 `applyFurniture`）目錄會變成物品定義。
- gameplay.json 已經有的家具（例如田地套組、地板）沿用原本的設定，目錄寫的欄位蓋過去。
- 新的家具直接用目錄的資料建立。
- 物品的 `price`（出貨箱收購價）一律等於二手價。不管在哪裡賣，都只能拿回一半。

**目錄內容**：
- 一共 **48 件**。其中 34 件是新的，用的是之前給的「室內家具」和「四季樹木與庭園」素材表裡沒用到的圖，例如床、地毯、衣櫃、老爺鐘、招財貓、櫻花樹、蘋果樹。
- 原本小葵花店裡一件一件賣的家具改成看目錄，花店只留種子。
- 節慶限定的家具不放進目錄，還是只在節慶時跟商人換：櫻花盆栽、稻草人、冬季樹。
- 釣魚獎盃不放進目錄。

### 1-2 購買入口

| 入口 | 說明 |
|---|---|
| 側邊欄 🪑 按鈕（鍵盤 **F**） | 在哪裡都能打開 |
| 小葵的選單 |「🪑 看『小葵的家具目錄』」 |

目錄是畫面中間的大視窗：
- 分頁：全部、一般家具、小擺飾、地毯、戶外、地板、壁紙、🎒 我的家具
- 每張卡片顯示：圖示、名稱、分類、佔幾格、說明、「揹包 N・已擺 M」

### 1-3 購買邏輯

**host 的規則**（`gameplay.ts` 的 `case 'buy_furniture'`）：

```
buy_furniture(item, count = 1):
  e = 目錄裡的 item；沒有 → 失敗 unknown
  count 要是 1～20 的整數
  cost = e.price × count
  if 金幣 < cost: return 失敗 'no_item'（畫面顯示「金幣不足」）
  金幣 −= cost
  揹包[item] += count
  furnitureBought[item] += count        // 買過的紀錄（賣掉、擺出去都不會減）
  return { item, count, cost }
```

**畫面**：
- **金幣不夠**：按鈕變灰，寫「金幣不足（🪙 價錢）」，滑鼠移上去顯示還差多少。
- **買到了**：跳出提示「🎉 買了 XX！放進揹包的『家具』分頁了（🪙 −價錢）」，那張卡片會亮綠框，並多出「🛠 擺放」和「二手賣」兩顆按鈕。

### 1-4 庫存與擺放聯動

- **揹包的「家具」分頁**：列出買了、還沒擺的家具（就是揹包裡的數量）。
- **點揹包裡的家具，或目錄的「🛠 擺放」**：進入裝修模式並拿著它。地板、壁紙直接換上。
- **擺放預覽**：滑鼠停的格子會畫出家具的樣子，佔幾格就畫多大，綠框代表可以擺，紅框代表不行。
- **收回**：在裝修模式點已經擺的家具，佔的任何一格都可以；它會回到揹包，數量 +1。家具疊在地毯上時，先收上面的家具。
- **二手賣出**：在目錄按「二手賣 🪙 X」。只能賣揹包裡的，擺出去的要先收回；也可以丟出貨箱，價錢一樣。

**host 的規則**：

```
place(scene, item, x, y):
  r = footprint(item, x, y)          // {x, y, w, h}
  if 有任何已擺的家具 q，「q 是地毯」等於「item 是地毯」，而且 footprint(q) 跟 r 重疊: 失敗 plot_busy
  // 也就是：地毯跟地毯不能重疊、家具跟家具不能重疊，但家具可以擺在地毯上
  揹包[item] −= 1；placed[scene] 加上 {item, x, y}

pickup(scene, x, y):
  hits = placed[scene] 裡 footprint 蓋到 (x, y) 的
  p = hits 裡不是地毯的那件 ?? hits[0]          // 先收上面的家具
  揹包[p.item] += 1；從 placed[scene] 拿掉 p

sell_furniture(item):
  if 揹包[item] == 0: 失敗 'no_item'
  揹包[item] −= 1；金幣 += floor(買價 × resaleRate)
```

**畫面這邊的檢查**（`pixel-stage.ts` 的 `placeProblem`）：佔的每一格都要檢查。

| 檢查 | 不行時的提示 |
|---|---|
| 有一格超出地圖 | 「這件要 2×2 格，往左上一點」 |
| 室內、戶外放錯地方 | 「這個要擺在室內／戶外」 |
| 有一格不能走（地毯看原本的地圖） | 「有一格放不下」 |
| 跟別的家具重疊 | 「這裡已經有東西了」 |
| 擋在門口 | 「不能擋在門口」 |
| 壓到可以互動的東西 | 「這裡已經有東西了」 |
| 她站在那裡 | 「她站在這裡」 |
| 會把通往門、出生點、互動物件的路完全擋住 | 「會擋住路，換個地方吧」 |

**繪圖**：先畫地毯，再由上往下畫其他家具。佔好幾格的家具，圖縮放到整個範圍並貼底。

### 1-5 存檔

存檔（DSH 的 save.json、demo 的 localStorage）裡和家具有關的三樣：

| 欄位 | 內容 |
|---|---|
| `furnitureBought` | 買了哪些家具：`{ "furn_bed_double": 1, "furn_rug_blue": 1 }`（V0.14 新增） |
| `inventory` | 哪些在揹包裡：`{ "furn_rug_blue": 1, … }`，也就是買了、還沒擺的 |
| `placed` | 哪些擺在哪個地圖的哪個座標：`{ "attic": [{ "item": "furn_bed_double", "x": 9, "y": 5 }] }`；x、y 是左上角那一格 |

- 舊存檔讀進來時，沒有 `furnitureBought` 就補一個空的；壞掉的值也一樣。
- 畫面資料 `GameView.furniture`：`bought` 是買過幾件，`placed` 是現在擺出去幾件（所有地圖加起來）。

## 2. 背景音樂

### 2-1 檔案

| 開發/ 的檔名 | 存成 | 長度 |
|---|---|---|
| 農場白天音樂.mp3 | `music/farm-day.mp3` | 2:14 |
| 夜晚房間音樂.mp3 | `music/night-room.mp3` | 2:53 |
| 下雨音樂.mp3 | `music/rain.mp3` | 7:48 |
| 礦洞冒險音樂.mp3 | `music/mine.mp3` | 0:49 |
| 酒館音樂.mp3 | `music/tavern.mp3` | 0:28 |

- **壓縮**：原檔是 256 kbps，五首共 27 MB。統一音量（loudnorm −18 LUFS）後轉成 96 kbps，共 9.8 MB。
- **不內嵌在 html 裡**（太大）。單機版放在 html 旁邊的 `music/` 資料夾，發給朋友時要一起給（zip 裡已經包好）。

### 2-2 規則：`packs/whale-girl-pixel/music.json`

由上往下，第一條符合的就播那首：

| 順序 | 條件 | 播哪首 |
|---|---|---|
| 1 | 在酒館 | 酒館 |
| 2 | 在礦洞 | 礦洞冒險 |
| 3 | 戶外、下雨或雷雨 | 下雨（室內聽不到雨） |
| 4 | 室內、傍晚或晚上 | 夜晚房間 |
| 5 | 任何地方、晚上 | 夜晚房間 |
| 6 | 其他 | 農場白天 |

選歌是純函數 `shared/music.ts` 的 `pickTrack`，有單元測試。換場景、天氣或時段變了，都會重新選。

### 2-3 播放（`client/pixel/music-player.ts`）

- **第一次點畫面或按鍵才開始播**：瀏覽器不准網頁自己出聲。
- **換歌**：舊的淡出、新的淡入，1.5 秒。同一首不會重播。
- **切到別的分頁**：暫停，切回來繼續。
- **開關**：側邊欄 🔊／🔇（鍵盤 **N**），記在瀏覽器裡。
- **讀不到音樂檔**：安靜地不放，不會一直重試。

**⚠ DSH 待確認**：
- DSH 版的 `lib/client.js` 沒有內嵌音樂，會去讀網頁旁邊的 `music/`。
- 如果 DSH 沒辦法提供插件資料夾裡的檔案，DSH 裡就不會有音樂，但不會出錯。
- 解法有兩種，要 DSH 那邊確認：
  1. host 提供一個讀檔的通道；
  2. 把音樂內嵌進 client.js，會多約 13 MB。
