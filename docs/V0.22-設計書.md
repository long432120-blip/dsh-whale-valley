# V0.22 設計書：繁簡雙語＋非同步社交

這一版加了四件事，**都不需要伺服器**：

1. **繁體／簡體切換**（⚙️ 設定），連兩岸用語一起換（程式碼→代码、網路→网络、存檔→存档…）
2. **聊天室**（💬）：先用本地模擬（鎮上居民和路過的旅人會回你），預留 `connectToServer(url)` 接 WebSocket
3. **串門**：在畫面正中央的串門視窗生成「邀請碼」貼給朋友，朋友輸入後進到你的農場（唯讀），可以點她說話、幫你澆水、留信；按 🏠 回家
4. **交易所**（🏪）：今日市集（系統商品）、我的攤位（攤位碼）、買朋友的貨、收款；寵物可以產生**領養碼**送給朋友

所有「碼」都帶校驗碼，改過的碼一律顯示「無效的交易碼／領養碼」。

## 1. 多語言（`src/client/i18n.ts`）

### 混合式：新介面用 key，其他自動轉

| 層 | 用在哪 | 檔案 |
|---|---|---|
| 語言包 key | V0.22 新增的介面（設定、聊天室、交易所、信箱、串門） | `locales/zh-TW.json`、`locales/zh-CN.json` 的 `ui` |
| 兩岸用語 | 所有畫面上的字：先換詞 | `locales/zh-CN.json` 的 `terms` |
| 逐字繁轉簡 | 所有畫面上的字：再換字 | `locales/t2s-chars.json`（2853 字，`tools/gen_t2s.py` 用 ICU 產生） |

舊介面、台詞、物品名、角色包 JSON、AI 的回覆都**不用改**，切到簡體時在畫面上自動轉。

```
class I18nManager
  locale ← localStorage['whale-pet:locale'] ?? (navigator.language 是 zh-CN/zh-SG/zh-Hans → 'zh-CN' : 'zh-TW')

  t(key, vars)
    s ← ui[locale][key] ?? ui['zh-TW'][key] ?? key       // 找不到就顯示 key，不會壞
    回傳 s 把 {n}、{name} 換成 vars

  convert(text)
    繁體、沒有漢字 → 原樣
    快取有 → 回快取
    s ← 用 terms 換詞（長的先換；「逐字轉過的寫法」也對得上，打字機效果一個字一個字出現也能換）
    s ← 逐字查表換字
    存快取（超過 5000 筆清空）

  install(document, root = body)              // 簡體才做
    先把 root 底下現有的文字節點、placeholder/title/aria-label/alt 轉好
    MutationObserver(root) 看新增的節點、文字變化、屬性變化 → convert
    略過 TEXTAREA、CODE、PRE、SCRIPT、STYLE（玩家打的字、碼不動）
    單機版 root = 整頁；DSH 版 root = 插件自己的區塊（不動 DSH 的介面）

  patchContext(ctx)                            // 畫布上的字
    只包「這一個」canvas context 的 fillText / strokeText / measureText（不改全域原型）

  static save(locale)  → 存 localStorage；呼叫的人 300ms 後 location.reload()
```

**為什麼切換要重新整理**：簡體轉不回繁體（「后」可能是「後」或「后」），重新載入最乾淨。每個動作都已經存檔，不會掉進度。

**加一個用語**：`locales/zh-CN.json` 的 `terms` 加一行 `"滑鼠": "鼠标"` 即可。

## 2. 聊天室（`src/client/chat.ts`、`src/shared/profanity.ts`）

### 本地模擬

```
class ChatService(def = social.json 的 chat)
  messages：最多 keep(60) 則，存 localStorage 'whale-pet:chat'（存不了就只放記憶體）

  send(raw)
    text ← 去頭尾空白、壓縮連續空白、截到 maxLength(80)
    空的                      → {ok:false, reason:'empty'}
    距離上一則 < 1.5 秒        → 'too_fast'
    跟 10 秒內自己說過的一樣   → 'repeat'
    text ← filter(text).text   // 過濾髒話
    加進紀錄（from:'me'）
    server 模式 → ws.send(JSON)；本地模式 → 1～2 個 bot 隔 1.2～4.5 秒回 replyFor(text)

  replyFor(text)
    找出 keywords 有任一個出現在 text 的 replies（英文不分大小寫）→ 隨機挑一條，從它的 lines 隨機挑一句
    都沒有 → fallback 隨機挑
    發話者從 bots 隨機挑（居民 or 旅人，兩個人回時不會是同一個）

  startAmbient() / stopAmbient()   // 聊天室打開時，每 25～60 秒有人自己聊一句
```

畫面最上面一直顯示 **📡 本地模擬：還沒連上伺服器，回你話的是鎮上的居民和路過的旅人**，不會讓人以為是真人。

### 敏感詞過濾（`makeFilter`）

```
makeFilter({blocked, allow})
  每個詞 → 正規式：字和字之間允許夾 0～3 個空白／標點／符號（擋「白 . 痴」「白_痴」）
  全形英數先轉半形、英文不分大小寫
  allow（幹嘛、樹幹、幹部…）出現的位置記下來，命中的範圍落在 allow 裡面就跳過（不會誤殺）
  命中 → 那幾個字（含中間夾的符號）每個換成一個「＊」
  回傳 {text, hit}
```

詞表在 `social.json` 的 `chat.blocked`（繁簡都要寫）。聊天、暱稱、留言、寵物名字都會經過它。

### `connectToServer(url)`

```
connectToServer(url, timeout = 8 秒)
  不是 ws:// 或 wss:// → false
  mode = 'connecting'
  new WebSocket(url)
    onopen   → mode = 'server'，回 true；系統訊息「已連上伺服器」
    onerror / 逾時 → 關掉、mode = 'local'，回 false；系統訊息「連不上，改回本地模擬」
    onmessage → JSON.parse（壞的丟掉）→ {type:'chat', nick, text, at} → 一樣過濾、截長度後加進紀錄
    onclose  → 回到本地模擬
```

伺服器協定只要收發 `{type:'chat', nick, text, at}`。測試用的連線網址欄位只在 `?dev` 模式出現。

## 3. 碼的格式（`src/shared/codec.ts`）

```
WV1.<種類>.<編碼>.<內容>.<校驗碼>
  種類：visit（邀請）/ reply（回信）/ stall（攤位）/ receipt（收款）/ pet（領養）
  編碼：j = JSON → UTF-8 → Base64URL
        z = JSON → deflate（CompressionStream）→ Base64URL（只有邀請碼用，約 400～4000 字）
  校驗碼：checksum("<種類>.<編碼>.<內容>", salt)
          = cyrb53(salt|text, 種子1) + cyrb53(text|salt, 種子7)，轉 36 進位
```

```
encodeCode(kind, payload, salt)
  body ← base64url(utf8(JSON.stringify(payload)))
  head ← `${kind}.j.${body}`
  回傳 `WV1.${head}.${checksum(head, salt)}`

decodeCode(code, salt, 允許的種類)
  去掉所有空白（聊天軟體會插換行）
  太長（> 30000）              → too_long
  正規式對不上                  → format
  種類不對（例如拿領養碼去買東西）→ kind
  重算校驗碼不一樣              → checksum     ← 手改任何一個字都會在這裡被擋
  Base64 / UTF-8 / JSON 壞掉     → format / json
  回傳 {ok:true, kind, payload}
decodeCodeAsync：多了解壓；解壓後超過 2 MB 直接拒絕（防壓縮炸彈）
```

### 規則層再檢查一次（`src/shared/trade.ts`）

校驗碼過了之後，`checkStall` / `checkReceipt` / `checkPet` / `checkReply` 會把每個欄位重新檢查、重新組一個乾淨的物件：

| 碼 | 檢查 |
|---|---|
| 攤位碼 | 物品存在、分類允許上架；數量 1～99；**單價在原價 0.5～5 倍之間**；7 天內 |
| 收款碼 | 是給我的；攤位上真的有這筆；**數量、總價跟攤位上一模一樣**；還沒收過；30 天內 |
| 領養碼 | 寵物種類存在；**好感、飽食在 0～上限之間**；取得時間不晚於產生時間；7 天內 |
| 回信碼 | 是給我的；信 120 字內；澆水的田最多 40 塊、去重；7 天內 |

再加上：

- **一張碼只能用一次**：`trade.redeemed` 記住兌換過的碼（60 天後清掉），再貼一次顯示「這張碼已經用過了」
- **轉移不複製**：上架時物品先從揹包扣掉（攤位保管）、產生領養碼時寵物立刻離開你家；取消上架才把東西退回
- **領養碼 24 小時冷卻**（`adopt.cooldownHours`）
- 不能買自己的攤位、不能拜訪自己；領養碼自己貼回去可以把寵物領回來（送錯了的後悔藥）

### ⚠️ 誠實說明：這樣能擋到哪裡

salt 寫在開源的程式碼裡，所以**校驗碼只能擋「手改碼裡的數字」這種隨手作弊**，擋不住會看程式碼、自己重算校驗碼的人。
但就算重算了校驗碼，規則層的範圍檢查還是會擋下「好感 9999」「單價 1」這種碼（測試裡有這個案例）。

剩下擋不了的：

- 自己改自己的 localStorage（單機遊戲本來就擋不了）
- 同一張攤位碼可以被好幾個朋友買（每個人都付錢、都拿到貨），**只有第一張收款碼能讓賣家收到錢**——離線沒辦法知道別人買過了

要真的防偽，需要伺服器簽章：把 `checksum()` 換成伺服器用私鑰簽的簽章、`redeemed` 搬到伺服器就好，碼的格式不用變。

## 4. 串門的狀態機（`src/client/game-shell.ts`、`src/client/visit.ts`）

```
     ┌──────── HOME ────────┐   輸入邀請碼（校驗碼、格式、期限都過）    ┌────── VISITING ──────┐
     │ bridge = 你的存檔    │ ─────────────────────────────────────▶ │ bridge = VisitBridge  │
     │ （LocalBridge／DSH） │ ◀───────────────────────────────────── │ （記憶體裡的唯讀副本） │
     └──────────────────────┘          🏠 回家（或重新整理頁面）       └───────────────────────┘
```

```
mountGame(root, opts)                       // 單機版、DSH 版都用這個掛畫面
  home ← opts.bridge
  chat ← new ChatService(social.chat)       // 聊天室跨畫面共用，串門時也在
  current ← mountPixelStage(root, {bridge: home, shell: api})

  api.visit(code, me)
    r ← decodeInvite(code)                  // 格式、校驗碼、期限 30 天、不能是自己
    失敗 → 回傳「無效的邀請碼」等訊息，畫面不動
    vb ← new VisitBridge(r.payload, ...)
    swap(vb, 'visiting')

  api.goHome() → swap(home, 'home')

  swap(bridge, mode)
    switching = true（避免連點）
    current.dispose()                       // 整個畫面拆掉：計時器、事件、音樂全部停
    try   current ← mountPixelStage(root, {bridge})
    catch 掛不起來 → 掛回 home（不會卡在半個朋友家）
    switching = false
```

### 串門視窗（畫面正中央）

⚙️ 設定最上面有兩顆大按鈕「🏡 生成邀請碼」「🚪 去朋友家」，按了都會打開同一個置中視窗（Modal 種類 `visit`，跟商店、交易所一樣有半透明黑幕，關掉才回到遊戲）：

| 分頁 | 內容 |
|---|---|
| 🏡 生成我的邀請碼 | 打開時自動生成；`textarea` 寬 100%、高 80px、11px 等寬字、會換行；下面「📋 一鍵複製」「❌ 關閉」兩顆大按鈕；最下面「🔄 重新生成」 |
| 🚪 輸入朋友的邀請碼 | 同樣大小的 `textarea`（可以貼有換行的碼）；下面「🚀 前往朋友的農場」「❌ 關閉」；碼有問題時錯誤訊息直接顯示在視窗裡 |

```
一鍵複製：
  navigator.clipboard.writeText(碼)
  失敗（雙擊打開的 html 常常沒權限）→ 選取 textarea + document.execCommand('copy')
  成功 → 視窗內提示「✅ 已複製到剪貼簿！」；都失敗 → 提示「已經幫你選好整串，請按 Ctrl+C」
剛生成好時：框框亮一下、整串選好，並試著自動複製一次
畫面每幾秒會重畫：打到一半的字（visitDraft）和游標位置都會保留
```

（順便修了一個舊問題：側邊欄面板每次重畫都會把焦點搶走，現在只有剛拉出來時才會。）

### 怎麼保證不會弄壞自己的存檔

- **VisitBridge 完全不碰 localStorage，也不打 host**。朋友的農場只活在記憶體，關掉就沒了
- 拜訪期間你的 bridge 根本沒有被掛著，不會被讀寫；拜訪狀態也不存，重新整理就回到自己家
- 邀請碼裡**沒有**朋友的揹包、金幣、日記、交易紀錄（`visitSnapshot()` 只放田、家具、建築、動物、寵物、好感）
- VisitBridge 只允許 `water`，其他動作（買賣、收成、釣魚、擺家具…）一律回 `'visitor'`，畫面顯示「在朋友家只能看看、聊天、幫忙澆水」
- 揹包、裝修、禮物碼、日記、AI 設定的按鈕在朋友家不顯示；底下有「👀 正在拜訪 ○○ 的農場（唯讀）✉️ 留信 🏠 回家」

### 留信與澆水怎麼回到朋友家

```
在朋友家澆水 → VisitBridge 記下澆過的田
✉️ 留信 → vb.makeReply(信) → 回信碼（reply）→ 複製傳給朋友
朋友在 📮 信箱貼上 → host 的 visit_reply：
  檢查碼 → 信放進 mailbox（過濾髒話、最多留 30 封）
  如果是今天的回信：那些田「現在還有作物」就幫他澆水（他那邊的規則再檢查一次）
```
