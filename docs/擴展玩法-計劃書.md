## E1：DSH 實機接上＋AI 工具

- `bridge-dsh.ts` 的 `fetchTransport`：`POST /plugins/dsh-whale-pet/<方法>`，送 JSON、收 JSON
- `src/host/index.ts`：註冊 6 個路由（`visit`、`getView`、`setScene`、`poke`、`act`、`gameplay`）
- tool `whale_pet_status`（唯讀：場景、季節、體力、好感、成熟的田）、`whale_pet_act`（只開放 `feed`、`water`、`harvest`，避免模型亂賣東西）
- ⚠ 路由與 tool 的註冊 API 都是推測，標在 README 的待確認清單
- 驗收：DSH 裡打開面板能玩；模型呼叫 `whale_pet_status` 拿得到狀態

## E2：內容 mod 擴充

- `mods/*.json` 可以追加或覆蓋：物品、作物、掉落、商人、季節（`calendar` 整個換掉）、解鎖、機器、收集、動物、建築、居民、節慶
- 同 id 覆蓋、新 id 新增；交換清單、掉落表、收集是附加
- 有錯的 mod 整個跳過並記警告
- 驗收：只放一個 mod，就能新增一個季節作物、一道料理、一位居民、一個節慶

## E3：玩家可操控角色

- 「🕹 自己走」切換：方向鍵／WASD 走主人，鯨魚娘跟在後面
- 走到門口就換地圖（兩人一起）；面向東西按 E／空白鍵：讓她去做（釣魚、種田、找居民）
- 原本的點擊操作照樣能用；主人位置不存檔
- 主人用程式畫的佔位像素人（16×32），之後可以換圖
- 驗收：只用鍵盤就能從房間走到海邊釣魚

## E4：即時戰鬥礦洞

- 需要 E3。小鎮的礦洞入口多一個「親自下去」
- 每層隨機擺石頭和怪物（史萊姆、蝙蝠）；空白鍵／J 攻擊面前的格子，武器決定傷害
- 主人有血量；歸零就被救出來、這趟撿到的東西掉一半
- 敲石頭出礦石；找到樓梯下一層；離開時把戰利品交給 host（`mine_loot`），host 檢查物品與數量上限
- 驗收：下到 3 樓、打倒怪物、帶回礦石；死掉時掉一半

## E5：建造與自由佈局

由核心第 4 輪完成（溫室、魚塘、馬廄、可擺放的田與裝飾）。這裡只追蹤驗收。

## E6：多人聯機（這次：禮物碼）

- 「🎁 寄禮物」：選物品和數量，產生一串禮物碼（含校驗碼）；寄出的東西從揹包扣掉
- 「收禮物」：貼上禮物碼就拿到；同一張碼在同一個存檔只能收一次
- 「名片」：產生一張顯示她的名字、好感等級、圖鑑進度的卡片碼，朋友貼上就能看
- 即時互訪、同一張地圖看到彼此：需要 DSH 有跨使用者的通道，**列為未完成**
- 驗收：A 寄出 3 條鱸魚，B 貼上禮物碼收到；同一張碼不能收第二次

## E7：節慶與限時活動

- `calendar.festivals: [{ id, name, emoji, season, day, greeting, shop }]`
- 節慶當天：狀態列顯示 🎉、她打招呼說節慶台詞、商人多一批限定商品、掉落表可以寫 `festival` 條件出現限定魚
- 預設四個：春「花祭」、夏「海灘祭」、秋「豐收祭」、冬「冰釣大會」
- 驗收：跳到節慶那天，看到 🎉、限定商品、釣得到限定魚

## 建議順序（這次的實作順序）

E2（跟核心一起做）→ E7 → E3 → E4 → E6 → E1。E1 放最後，因為它只能寫好、無法實測。
