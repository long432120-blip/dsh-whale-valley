## 0. 總原則

1. **完全資料驅動**。任務、魚、釣具、稀有度、女神、天氣、動物都寫在 JSON。程式只認欄位，不認名字。
   - 加一條任務線、一種天氣、一隻動物，都不用改程式。
   - 也可以不改原檔，在 host 的 `mods/` 放一個 JSON（見第 6 節）。
2. **host 是唯一的真相**。所有亂數和結果都在 host（demo 是 `LocalBridge`）算好，再存檔；畫面只負責演。
   - 亂數種子存在存檔裡，同樣的存檔加同樣的動作，一定得到同樣的結果，所以可以寫單元測試。
3. **遊戲時間 = 現實時間 + `clockOffset`**。睡覺（快轉）就是把 `clockOffset` 往前加。
   - 作物、動物、天氣、好運期限都用遊戲時間算。
   - 「主人多久沒來」仍然用現實時間算。

## 1. 任務（引導）系統

### 1.1 狀態機

`tutorial_step` 就是存檔的 `game.quest.step`（從 0 算）。每一步只有兩個狀態：**進行中**、**完成 → 下一步**。

```
          ┌──────────── 動作成功（caught / sold / traded / planted / slept / harvested…）
          │             或走進地圖（enter）
          ▼
 [step N 進行中] ── 條件吻合，progress += count ──▶ progress ≥ count？
          ▲                                            │是
          │否                                          ▼
          └────────────── 等下一個訊號        發 reward、寫 questLog
                                                         │
                         還有下一步 ◀────────────────────┤
                         step = N+1, progress = 0        │最後一步
                                                         ▼
                                       done[chain] = true → 找下一條 requires 已滿足的任務線
```

新手引導 `tutorial` 共 6 步：

| step | id | 左上角任務框 | 完成條件 | 指引目標 | 獎勵 |
|---|---|---|---|---|---|
| 0 | fish | 📌 去花園的池塘釣一條魚 | `caught` 任何 `fish` | garden / pond | 🪱 蚯蚓 ×5 |
| 1 | sell | 📌 去小鎮找老陳賣魚 | `sold` 給 `fishmonger`（老陳的魚攤）、分類 `fish` | town / fisher | 🪙 30 |
| 2 | seeds | 📌 去花店找小葵買種子 | `traded` 和 `florist` 換到 `seed`，**或揹包本來就有種子** | town / florist | — |
| 3 | plant | 📌 回花園把種子種下去 | `planted` | garden / plot-1 | — |
| 4 | sleep | 📌 回房間睡一覺（快轉時間） | `slept` | room / bed | — |
| 5 | harvest | 📌 去花園收成 | `harvested` | garden / plot-1 | 🪙 100 |

第 5 步是額外加的：睡醒之後讓玩家看到「睡覺會讓作物長大」，形成完整的循環。
做完之後自動接 `town-life`（`requires: "tutorial"`）：找阿綱打招呼 → 去海邊 → 釣一條史詩以上的魚 → 餵她吃一道料理。

### 1.2 介面（`gameplay-types.ts`）

```ts
interface QuestFile { version: 1; nagEverySec: number; chains: QuestChain[] }

interface QuestChain {
  id: string; name: string;
  requires?: string;              // 前一條任務線做完才開始
  steps: QuestStep[];
  doneSay?: string[];             // 整條做完時她說的話
}

interface QuestStep {
  id: string;
  task: string;                   // 左上角「📌 …」
  say: string[];                  // 進到這一步時，頭頂氣泡依序說
  nag?: string[];                 // 每 nagEverySec 秒沒進度，輪流說一句
  target?: { scene: string; object?: string };  // 指引箭頭：哪張地圖、哪個 Tiled 物件名
  done: QuestCondition;
  count?: number;                 // 做幾次（預設 1）
  reward?: Record<ItemId, number>;
}

interface QuestCondition {
  event?: GameEvent['type'] | 'enter';
  item?: ItemId; category?: string;
  rarity?: Rarity;                // 至少這個稀有度
  shop?: ShopId; npc?: string; scene?: string;
  have?: { item?: ItemId; category?: string; count?: number };  // 揹包已經有就算完成
}

// 存檔
GameState.quest: { chain: string | null; step: number; progress: number;
                   done: Record<string, true>; nagAt: number; last: QuestLog | null }
```

### 1.4 綁定事件觸發（host 端）

```ts
// 每個動作成功後（applyAction 尾端）
function applyAction(g, action, defs, now) {
  g = tickGame(g, now, defs)                     // 先把時間結算到現在
  r = run(g, action, defs, now, rnd)             // 規則本身
  if (r.ok) r.game = advanceQuests(r.game, [triggerOf(r.event)], defs, now)
  return r
}

// 換場景（state.setScene）：走進地圖也是一種訊號
setScene(save, to) → advanceQuests(game, [{ event: 'enter', scene: to, items: [], count: 1 }], defs, now)

// 事件 → 訊號
triggerOf(e):
  caught    → items=[e.item], count=e.count
  sold      → items=[e.item], shop=e.shop, count=e.count
  traded    → items=keys(e.get), shop=e.shop
  planted   → items=[e.seed]
  talked    → npc=e.npc        … 其他依此類推

// 推進（節錄自 advanceQuests）
loop (最多 20 次，避免 have 條件連鎖跳步時無窮迴圈):
  step = chains[q.chain].steps[q.step]
  hit  = Σ t.count for t in triggers if matches(step.done, t)
  triggers = []                                   // 一個訊號只推一步
  if q.progress + hit < (step.count ?? 1) and not hasNow(step.done, inventory):
      q.progress += hit; break
  inventory += step.reward
  q.last = { chain, step: step.id, task, reward, chainDone: 是最後一步, at: now }
  q = 是最後一步 ? firstQuest(done ∪ {chain}) : { step: q.step + 1, progress: 0 }

matches(c, t):
  c.event == t.event
  且 (沒寫 shop 或 shop 相同) 且 (沒寫 npc 或相同) 且 (沒寫 scene 或相同)
  且 (沒寫 item 或 t.items 含 item) 且 (沒寫 category 或某個 item 屬於該分類)
  且 (沒寫 rarity 或某個 item 的稀有度 ≥ rarity)
```

`have` 讓任務不卡關。例如玩家早就有種子，「買種子」這一步在下一個訊號時會直接跳過。

### 1.5 綁定地圖座標（畫面端）

任務只寫 **Tiled 物件的名字**（`pond`、`fisher`、`plot-1`、`bed`），不寫座標。改地圖、搬位置都不用改任務。

```ts
// 每一幀（finishDraw 之後）
drawGuide(now):
  t = view.game.quest.target
  if t.scene == 目前地圖:
      rect = interactables[t.object] ?? doors[t.object] ?? spots[t.object]
      在 rect 正上方畫金色箭頭，上下浮動（sin(now/200)）
  else:
      door = routeTo(t.scene)[0]           // 世界地圖 BFS：往目標地圖要先走哪個門
      在那個出口畫金色箭頭，指向地圖外     // 就是「畫面外的目標 → 邊緣小箭頭」
```

地圖不會比畫面大（20×12 格整張顯示），所以「目標在畫面外」只有一種情況：**目標在別張地圖**。
這時箭頭畫在通往那張地圖的出口上，也就是地圖邊緣。

**點左上角任務框** → `travelTo(t.scene)`：她自己一張一張地圖走過去，到了以後 `approach(目標)`，走到旁邊就直接做（釣魚、打開老陳的面板、睡覺…）。

### 1.6 頭頂氣泡、常駐任務框、催促

```ts
onQuestView(view):                        // 每次 host 回傳新狀態
  if questLast.at > 已看過的時間: toast「✅ 完成：{task} 獎勵 …」；整條做完 → speak(chain.doneSay)
  if 任務步驟變了: speak(step.say)
  questBox.text = `📌 ${task}` + (need > 1 ? ` ${progress}/${need}` : '')

speak(lines): 排進氣泡佇列；nagAt = now + nagEverySec * 1000
updateGuide(now):                         // 每一幀
  氣泡跟著她的頭（對話框、換場景、她不在時先藏起來）
  每句顯示 2.2 秒 + 字數 × 0.11 秒，時間到換下一句
  if now > nagAt 且 沒有氣泡、沒開面板、沒在釣魚:
      speak([nag[i++ % nag.length]])      // 輪流換句話說，不會一直重複同一句
```

- 任務框：狀態列正下方，永遠顯示。
- 氣泡：不是彈窗，也不擋點擊（`pointer-events: none`），玩家照樣可以點她身後的田和門。
- 打開畫面時（`visit`）會再說一次目前任務的 `say`，關掉再回來的玩家也知道要做什麼。

## 4. 天氣與「快轉時間」

```ts
// 每天的天氣：只看「第幾天」和季節權重，不吃存檔亂數 → 同一天重開幾次都一樣，也能預先算明天
weatherAt(now):
  r = rngFrom(dayIndex(now) * 7919 + 17).next()
  依 weather.seasons[季節] 的權重抽一個 id（沒有 weather.json → 舊的 rainChance 二選一）

// 雨天早上自動澆田（tickGame 裡，離線、睡覺都會經過）
for t in mornings(lastTickAt, now, wakeHour):     // 這段時間裡每一個早上 6 點
  if weatherDef(weatherAt(t)).wet:
    每一塊有作物的田 wateredUntil = max(wateredUntil, t + 1 天)

// 快轉：睡覺（只能在房間的床，state.act 檢查場景，不對就回 not_here）
run('sleep'):
  to = nextWake(now, wakeHour)                     // 下一個早上 6 點
  g  = tickGame({ ...g, clockOffset: g.clockOffset + (to - now) }, to)   // 中間的作物、動物、下雨照常結算
  stamina = max
  event slept { from, to, weather: weatherAt(to), watered: 這次被雨澆到的田數 }

// 畫面
點床 → 面板「😴 睡覺／還不睏」 → 畫面淡黑＋💤 → act(sleep) → 淡回
     → toast「🌅 早安！今天是 🌧️ 雨天，下雨了，N 塊田都自動澆好囉！」＋她頭頂說同一句
drawWeather(now):                                  // 每一幀
  w = view.weather
  if w.tint: 整張地圖蓋一層色
  if w.particles: 室外地圖畫 count 條斜線雨，位置用 (i, now) 算，不存狀態（室內沒有雨滴，色調減半）
  if w.flash: 平均每分鐘 perMinute 次（每幀擲一次機率），白光約 0.2 秒內暗下來；室內只透一點光
```

`view.game.fishing` 帶著目前的竿、餌、剩幾個餌、`waitMs`（加了竿和餌的等魚時間）、`rare`（目前史詩、傳說的總倍率）。揹包最下面一行會顯示竿、餌和等魚秒數。

## 5. 動物：成長、產出、交易

```ts
// 買：只買得到幼崽
run('buy_animal', kind):
  檢查建築已解鎖、容量、錢
  animal = { kind, name: '小雞3', bornAt: now, fedUntil: now, mood: 60,
             readyAt: now + baby.growHours + hours }      // 長大之後才開始算第一次產出
  event animal_bought

// 每次結算（tickGame → produce）
produce(a, now, lucky):
  while 沒有待收的產品 and readyAt <= now:
    if 吃飽了（fedUntil ≥ readyAt）:
      mood += 5
      if mood ≥ minMood:
        goodChance = min(0.95, (mood/100*0.4 + friendship/1000*0.3) × (lucky ? goodProduct : 1))
        pending = rnd() < goodChance ? goodProduct : product
    else mood -= 20
    readyAt += hours

// 畫面上的成長
view.animals[i].adult    = now ≥ bornAt + growHours
view.animals[i].growsAt  = bornAt + growHours           // 面板顯示「🍼 幼崽，還要 N 小時 長大」
view.animals[i].sellPrice = animalPrice(a)

// 賣給商人
animalPrice(a) = round((adult ? sellPrice.adult : sellPrice.baby) × (1 + min(friendship,1000)/2000))   // 好感越高最多 +50%
run('sell_animal', id):
  coins = animalPrice(a);  0 → not_for_sale
  移除這隻、coin += coins、stats.earned += coins
  event animal_sold { name, coins }       // 畫面 toast「👋 把「小雞3」賣給商人了：🪙 +150」
```

## 6. 擴充：玩家自己加任務、天氣

放一個 `mods/*.json`（host 的存檔目錄），或直接改 `packs/whale-girl-pixel/` 下的檔案：

```json
{ "version": 1,
  "questChains": [{
    "id": "night-fisher", "name": "夜釣達人", "requires": "town-life",
    "steps": [{ "id": "legend", "task": "釣到一條傳說魚", "say": ["聽說月亮出來的時候，錦鯉王會浮上來…"],
                "target": { "scene": "garden", "object": "pond" },
                "done": { "event": "caught", "rarity": "legendary" }, "reward": { "bait_magic": 10 } }] }],
  "weatherTypes": [{ "id": "fog", "name": "霧", "emoji": "🌫️", "wet": false, "rareBonus": 0.1, "tint": "rgba(220,220,230,0.35)" }],
  "weatherSeasons": { "autumn": { "sunny": 5, "rainy": 3, "storm": 1, "fog": 2 } } }
```

- `questChains` / `weatherTypes`：同 id 覆蓋、新 id 新增。`weatherSeasons`：整季覆蓋。
- 檢查（`validateGameplay`）會擋下這些錯誤，有錯的 mod 整個跳過並在 log 警告：
  - 任務：步驟沒有 `event` 也沒有 `have`、條件或獎勵用到不存在的物品、商人、居民，`requires` 指到不存在的任務線，任務線 id 重複。
  - 天氣：權重是負數、權重寫到不存在的天氣、一種天氣都沒有。
  - 釣魚：釣具的 `bite` 或 `rare` 倍率 ≤ 0、稀有度不是 common / epic / legendary、女神機率不在 0～1。
  - 幼崽：`growHours` 是負數。
- `target` 寫錯地圖或物件名不會讓遊戲壞掉，只是不會畫箭頭。改完地圖跑 `npm run check:pixel` 會一起檢查。

## 8. 說明與限制

- **UI 沒有照抄 my_ai_town**。那個專案沒有授權條款，預設是「保留所有權利」，而且是 Godot／GDScript，沒辦法直接搬到這裡的 Canvas＋HTML。所以 UI 用本專案自己的像素風格重做：木框面板、像素字距、頭頂氣泡、金色箭頭。
- **NPC 立繪**是你提供的圖。處理方式：綠幕去背、只留人物那一塊（女神和阿綱原圖角落的「豆包 AI生成」浮水印因此被裁掉；`ASSETS.md` 有註明來源）、縮成遊戲大小。畫面上用呼吸縮放、輕微搖擺、說話時跳一下來做「微動」。頭像用的是同一張圖的大尺寸版本。
- **好運期限用遊戲時間算**。睡一覺就會跳到隔天 6 點，所以好運會在醒來時結束。這符合「持續到隔天」的規格。
- **女神 1% 很低**。測試時想看彈窗，可以把 `fishing.json` 的 `goddess.chance` 暫時改成 `1`。
