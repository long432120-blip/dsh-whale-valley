## 地圖

```
          閣樓（升級房屋後）
            │
          房間 ── 花園 ── 牧場 ── 小鎮（居民、鐵匠、礦洞入口）
                   │       │
                  海邊    溫室（蓋好後）
```

- 新增 5 張地圖：牧場、海邊、小鎮、溫室、閣樓。都是 20×12 格，用 `pixel_art.py` 產生、可以用 Tiled 改
- 地圖邊緣的「出口」就是門物件，跟現在的門一樣運作
- **上鎖**：任何門或互動物件加屬性 `unlock = 解鎖 id`，沒解鎖前點它會跳出解鎖面板（要多少金幣、材料）

## 共通的新規則

- **金幣**是一般物品 `coin`，所以既有的「交換」直接能用金幣買賣
- 新動作一律走 `bridge.act({ type, … })`，失敗不扣東西
- 存檔欄位只增不改；`normalizeGame` 補預設值，舊存檔照常讀
- host 不認識地圖：需要地圖資訊的檢查（家具會不會擋路）在畫面端先做，host 只檢查格式和數量

## 第 2 輪：經濟與擴建

| 項目 | 資料（gameplay.json） | 動作 | 畫面 |
|---|---|---|---|
| 出貨賣錢 | 物品 `price`；商人 `mode: "sell"` | `sell {item, count}` | 牧場的出貨箱：揹包物品列表＋賣 1／全部 |
| 金幣買東西 | 交換的 `give` 寫 `coin` | 沿用 `trade` | 狀態列顯示金幣 |
| 開墾、解鎖 | `unlocks: { id: { name, cost, requires? } }` | `unlock {id}` | 上鎖的田、門、設施畫 🔒，點了開解鎖面板 |
| 加工要時間 | `machines: { id: { recipes: [{ give, get, minutes }] } }` | `machine_start {machine, recipe}`、`machine_collect {machine}` | 牧場的果醬機、燻魚爐；做好了上面冒 ✨ |
| 圖鑑收集獎勵 | `collections: [{ items, reward }]` | 釣到時自動判斷 | 圖鑑顯示每組進度；完成時提示＋台詞 |
| 第二個釣點 | 掉落表 `sea`、`river` | 沿用 `fish` | 海邊地圖（海、河口） |

驗收：賣東西拿到金幣 → 買得到種子 → 花金幣開墾牧場的田並種下 → 果醬機放草莓、過時間拿到果醬 → 集滿一組魚拿到獎勵 → 海邊釣到海魚。

## 第 3 輪：釣魚小遊戲、動物養殖

| 項目 | 資料 | 動作 | 畫面 |
|---|---|---|---|
| 釣魚小遊戲 | `fishing.minigame`：綠區大小、指針速度 | `fish {table, quality}`：`miss` 跑掉、`good` 一般、`perfect` 有機會雙倍 | 咬鉤時跳出橫條，指針來回，點一下（或空白鍵）停 |
| 小遊戲開關 | 存在瀏覽器 | — | 揹包面板底部「🎣 小遊戲：開／關」；關掉就是原本等 3 秒 |
| 雞舍、畜棚 | `buildings: { coop: { levels: [{ capacity, cost }] } }` | 建造用 `unlock`；升級 `upgrade_building {building}` | 牧場上的建築，點了開動物面板 |
| 動物 | `animals: { chicken: { building, price, product, goodProduct, hours, feed } }` | `buy_animal {kind}`、`feed_animals {building}`、`pet_animal {animal}`、`collect_animals {building}` | 動物在圍欄裡走來走去；面板列出心情、好感、產品 |
| 心情與好感 | 規則：每天摸一次 +好感；沒吃飽心情掉；心情 ≥ 70 有機會出高級品 | — | 面板上的 ❤ 與表情 |

雞（蛋／大蛋）、鴨（鴨蛋／鴨毛）、牛（牛奶／大瓶牛奶）、羊（羊毛／上等羊毛）、豬（松露，只在心情好時找到）。

驗收：建雞舍 → 買雞 → 餵乾草、摸摸 → 隔天收蛋 → 心情好時拿到大蛋 → 升級雞舍容量變大；小遊戲 miss 會跑掉、perfect 有時雙倍、關掉就是等待式。

## 第 4 輪：房屋裝修、建設

| 項目 | 資料 | 動作 | 畫面 |
|---|---|---|---|
| 擺家具 | 物品 `place: { blocking }` | `place {scene, item, x, y}`、`pickup {scene, index}` | 「🛠 裝修」模式：揹包選家具 → 點格子；會擋住門或作息地點就不給放 |
| 地板、壁紙 | 物品 `decor: { kind, replace: { 舊圖塊: 新圖塊 } }` | `decorate {scene, item}` | 整個房間的地板或牆換掉；換新的時舊的退回揹包 |
| 升級房屋 | `unlocks.house_upgrade` | `unlock` | 房間多一扇門通往閣樓 |
| 溫室 | `unlocks.greenhouse`；`farming.greenhouseScenes` | `unlock` | 牧場的溫室門開放；溫室裡的田不分季節、永遠濕潤 |
| 魚塘 | `unlocks.fishpond`；掉落表 `fishpond` | `unlock` | 牧場的魚塘開放釣魚 |
| 馬廄 | `unlocks.stable` | `unlock` | 有馬之後她在戶外走路變快 |
| 自由設計農場 | 物品 `place: { plot: true }`（可移動的田）、裝飾物 | `place`、`pickup` | 牧場可以自己擺田、圍籬、花；擺下的田跟一般的田一樣能種 |

驗收：買家具擺進房間、收回來 → 換地板 → 升級房屋走進閣樓 → 蓋溫室在冬天種草莓 → 在牧場擺一塊田並種下。

## 第 5 輪：NPC 社交、戀愛結婚

| 項目 | 資料 | 動作 | 畫面 |
|---|---|---|---|
| 居民 | `npcs: { id: { name, emoji, loves, likes, dislikes, lines, events } }`；Tiled `npc` 物件 | `talk {npc}`（每天第一次 +好感）、`gift {npc, item}`（每天一次） | 小鎮三位居民；對話框換成對方的名字和頭像 |
| 好感 | 每位 0～1000，每 100 一顆心 | — | NPC 面板顯示心數、今天聊過／送過沒 |
| 劇情事件 | `events: [{ id, minFriendship, lines }]` | 聊天時達到門檻自動觸發一次 | 連續多句對話 |
| 戀愛、結婚 | `marriage: { item, minAffection }`；好感等級加「戀人」「伴侶」 | `propose`（用藍色貝殼） | 告白事件；之後狀態顯示已結婚 |
| 婚後幫忙 | `marriage.helps` | 每天第一次結算時自動執行 | 「她早上幫你澆了 N 塊田、摸了動物」提示 |

居民：漁夫老陳（愛魚）、花店小葵（愛花和草莓）、鐵匠阿鋼（愛礦石；也賣工具）。

驗收：每天跟居民聊天、送禮提升好感 → 到門檻看到劇情 → 鯨魚娘好感到「戀人」→ 送藍色貝殼結婚 → 隔天早上田被澆好了。

## 第 6 輪：礦洞（派遣制）

| 項目 | 資料 | 動作 | 畫面 |
|---|---|---|---|
| 派遣 | `mine.zones: [{ from, to, minutes, monsters, loot, needPickaxe }]` | `mine_start {floor}`、`mine_collect` | 小鎮的礦洞入口：選樓層；她離開期間地圖上看不到她 |
| 鎬子 | 物品 `equip: { slot: "pickaxe", power }` | 鐵匠交換 | 鎬子等級決定能去多深 |
| 戰鬥 | 怪物 `hp`、`atk`；武器 `power`、防具 `defense` | 收成時一次模擬 | 回來時的報告：打倒幾隻、受了多少傷、帶回什麼 |
| 武器、防具、稀有材料 | 掉落表裡的裝備與寶石 | — | 揹包「裝備」分頁，自動用最好的 |
| 更深層 | 存檔記最深樓層；只能去到最深＋1 | — | 面板顯示最深紀錄 |

驗收：派她去 1 樓 → 等時間 → 帶回銅礦、打倒史萊姆 → 鐵匠換更好的鎬子 → 能去更深 → 拿到武器後戰鬥更順。

## 風險

| 風險 | 影響 | 對策 |
|---|---|---|
| DSH 宿主 API 還沒在實機驗證 | 全部玩法只在 Demo 驗證 | 規則與畫面分離；接上時只需實作 `Transport`（擴展 E1） |
| 美術量（建築、動物、NPC、家具） | 畫面粗糙 | 建築用程式畫的佔位圖塊；動物、NPC、家具先用 emoji；之後換圖不用改規則 |
| 系統一次加很多 | 數值失衡、太難懂 | 每個系統都有預設數值和提示；全部是 JSON，可以調 |
| 家具擋路 | 她走不到門或作息地點 | 畫面端放置前先算一次路徑，擋到就不給放 |
| 客戶端送來的結果（小遊戲分數） | 可以作弊 | 單機遊戲可接受；host 仍檢查數量上限，聯機前要改成 host 判定 |

## 實作與計劃的差異（第 3 版補）

| 項目 | 計劃 | 實際 | 原因 |
|---|---|---|---|
| 自由設計農場佈局 | 田地、裝飾自由擺放 | 田地套組、花圃、石板路、燈籠、家具可以自由擺；**建築（雞舍、畜棚、溫室…）的位置固定**在 Tiled 地圖上 | 搬動建築要連門、圍欄、站位一起重算，風險高；改位置目前用 Tiled 編輯 |
| 第二個釣點 | 河或海 | 海、河口都做了，另外加了牧場魚塘 | 地圖空間夠 |
| 熔爐 | 未列 | 放在小鎮鐵匠舖旁邊 | 礦石要先煉成金屬錠才能換鎬子 |
| 小遊戲判定 | host 判定 | 畫面判定品質，host 只收 miss／good／perfect，釣到什麼仍由 host 決定 | 單機可接受；聯機前要改成 host 判定（風險表已列） |
| 家具擋路檢查 | — | 畫面端放置前算路徑，host 只檢查格式和數量 | host 不認識地圖 |
| 美術 | 佔位 | 建築是程式畫的圖塊；動物、居民、家具、怪物、礦石用 emoji | 依風險表的對策 |

## 第 7 輪：V0.5「完全體」

全部資料驅動。介面、JSON 範例、偽代碼都在〈[V0.5-設計書](V0.5-設計書.md)〉，這裡只列範圍和驗收條件。

| 項目 | 資料 | 動作／事件 | 驗收 |
|---|---|---|---|
| 任務引導（`tutorial_step`） | `quests.json` | 所有成功的動作 → `triggerOf` → `advanceQuests`；換場景 → `enter` | 新存檔從房間做到收成，每一步都有任務框、氣泡、箭頭；一分鐘沒進度會催 |
| 老陳搬到小鎮擺魚攤 | `gameplay.json` 的 `shops.fishmonger`（`buys: ["fish"]`）、`shops.fisher`；地圖 town 的 `fisher` | `sell` 加 `shop` 參數，不收的分類回 `wrong_shop` | 只能賣魚給老陳；教學第 2 步只認老陳 |
| 釣竿、魚餌、稀有度 | `fishing.json` 的 `gear`、`rarity`、`rarities` | `set_gear`；`caught` 帶 `rarity`、`bait` | 好竿好餌等魚時間變短、稀有魚變多；餌會用完 |
| 湖中女神、好運 | `fishing.goddess` | `caught.goddess`；`GameState.luckUntil` | 約 1%；好運到隔天 6 點；釣魚、礦洞、動物高級品都受影響 |
| 天氣 | `weather.json` | 每天由日期決定；`tickGame` 的雨天早上澆田 | 雨天早上田是濕的；雨天、雷雨 +20%；畫面有雨和閃電 |
| 睡覺快轉 | `gameplay.json` 的 `sleep` | `sleep` → `slept`；只能在 `sleep.scenes` | 跳到隔天 6 點、體力全滿；中間照常結算 |
| 動物成長、交易 | `animals.json` 的 `baby`、`sellPrice` | `buy_animal` 買幼崽；`sell_animal` → `animal_sold` | 幼崽長大前不產出；賣價依長大與否、好感 |
| NPC 立繪 | `npcs.*.sprite`、`portrait` | — | 小鎮三位居民用立繪、會微動；對話框頭像是立繪 |

和原始需求不同的地方：
- 教學多了第 6 步「收成」，讓玩家看到睡覺會讓作物長大。
- UI 沒有照抄 my_ai_town（沒有授權條款，而且是 Godot），改用本專案的像素風格重做。
