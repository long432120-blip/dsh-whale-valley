## 2. 一個動作可以用自己的一張圖

她原本的動作（坐、睡、揮手…）都在同一張動作表裡。新的兩張圖是側面、大小也不一樣，所以讓動作可以帶自己的圖：

```jsonc
// character.json → actions.clips
"tavern_sit": { "row": 0, "frames": [0], "fps": 1, "loop": 0,
  "sheet": { "src": "assets/whale-girl-tavern-sit.png", "frameWidth": 75, "frameHeight": 132, "footY": 131, "drawScale": 0.33333, "faces": "right" } },
"swim": { "row": 0, "frames": [0, 1], "fps": 3, "loop": 0,
  "sheet": { "src": "assets/whale-girl-swim.png", "frameWidth": 89, "frameHeight": 67, "footY": 60, "drawScale": 0.42, "faces": "right" } }
```

- **`sheet`**：這個動作用這張圖，不用動作表。
- **`faces`**：圖朝哪邊。她面向另一邊時，左右翻轉。
- **方向**：一般動作表的動作會讓她轉正面；有自己圖的動作照目前方向畫。
- **原圖**：去背後放在 `assets/source/whale-girl-tavern-sit.png`、`whale-girl-swim.png`。
- **大小**：縮放比例照坐姿換算，坐著連凳子約 44 地圖像素高。游泳圖用同一個比例，再放大 1.25 倍，讓她在浴池裡看得清楚。

## 3. 酒館坐著喝（`tavern_sit`）

- **四張餐桌**：點了她會走到桌邊坐下、拿著木杯，揹包打開在「吃的」分頁。關掉揹包才起身。

## 4. 浴池游泳（`swim`）

- **泡完澡就下水**：泡澡後在浴池裡左右游 15 秒（`leisure.json` 的 `bath.swimSeconds`），游到邊邊會轉身。身體隨水浮上浮下，頭上偶爾冒一句話，台詞在 `leisure.json` 的 `lines.swim`。
- **自己閒晃時**：走到浴池旁（地點 `tub`）也會下水游一下，大約 9～16 秒，這時不加數值。
- **上岸**：點她（或點畫面任何地方）就提早上岸；換場景也會先上岸。
- **游的範圍**：浴室裡動作是 `bath` 的熱區（浴池），左右 20%～80%，水面在範圍高度的 47%。

**偽代碼**：

```
startSwim(ms):
  浴池範圍 → 水面的左右兩端 x0、x1 和高度 y（地圖像素）
  記住她原本站的格子；她移到水面中間、面向右、播 swim 動作
  不讓作息帶她走（idleUntil = ∞）

每一幀 updateSwim(dt):
  時間到 → endSwim()
  往面向的方向游（每秒 16×actorScale 像素），碰到 x0／x1 就轉身
  y = 水面 + 一點點上下浮動
  每 6～11 秒冒一句 lines.swim

endSwim():
  回到原本站的格子、停止動作、過一下再照作息走
```
