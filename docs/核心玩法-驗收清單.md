## 怎麼驗收（雙擊 `demo/pixel-standalone.html`）

先按「🗑 重置存檔」。很多東西要錢，想快速驗收可以先多釣魚、多賣。

| # | 操作 | 應該看到 |
|---|---|---|
| 1 | 去花園釣魚，經花園右邊出口到牧場，點 📦 出貨箱「全賣」 | 狀態列的 🪙 增加 |
| 2 | 點牧場左下有 🔒 的田 | 解鎖面板；錢夠就解鎖，田可以種 |
| 3 | 解鎖果醬機、放草莓（或胡蘿蔔） | 上面出現 ⏳；時間到變 ✨，拿到成品 |
| 4 | 解鎖雞舍、買雞、在花園商人買乾草、餵、摸 | 雞在圍欄裡走；隔天（⏭ 跳到明天）收到雞蛋 |
| 5 | 釣魚 | 跳出時機條；黃色區按下有時釣到兩條；揹包最下面可以關 |
| 6 | 從花園下方出口到海邊釣魚 | 釣到鯖魚、龍蝦等海魚；圖鑑新增 |
| 7 | 🛠️ 裝修：揹包點家具，點房間空格 | 家具出現；擋住門的位置會被拒絕；再點家具收回 |
| 8 | 揹包點地板或壁紙 | 房間整片換掉 |
| 9 | 點房間左下的梯子 → 解鎖房屋擴建 | 可以走進閣樓 |
| 10 | 牧場右邊到小鎮，點小葵 | 面板：聊天、送禮、看商品；聊天時對話框是她的名字和頭像 |
| 11 | 點小鎮右上的洞口，買鎬子後「派她去」 | 她從地圖上消失；時間到「接她回來」看到礦洞報告 |
| 12 | 好感到 300、拿到藍色貝殼 | 揹包出現告白按鈕；結婚後隔天早上她說幫忙澆了幾塊田 |

## 已知限制

- **沒有在 DSH 實機上跑過**；接上的方式見 README 的待確認清單
- 建築、動物、居民、家具是佔位美術（程式畫的圖塊、emoji），不同平台的 emoji 長得不一樣
- 小遊戲的品質由畫面判定、家具擋路由畫面檢查；單機沒問題，聯機前要改成 host 判定
- 數值是初稿，還沒有長時間實玩；都在 `gameplay.json`
