## 2. 坐到椅子上（`seat`）

```jsonc
// interactables.json → tavern → hotspots
{ "id": "table-a", "stand": { "x": 128, "y": 660 }, "seat": { "x": 185, "y": 662 },
  "face": "right", "pose": "tavern_sit", "action": { "type": "eat" } }
// spots（她自己閒晃時坐）
"seat-a": { "x": 128, "y": 660, "face": "right", "action": "tavern_sit", "seat": { "x": 185, "y": 662 } }
```

- **`seat`**：坐下的位置，是椅腳的位置（原圖像素）。有 seat 就一定要有 pose，檢查會擋。
- **擺姿勢時**：她從站位移到 seat。
- **說話、吃東西時**：繼續坐著，不換成站著的動作，用愛心表情代替。
- **起身**：先回到站位那一格再走，不會從椅子斜著滑走。
- **被點到、揮手**：換成別的動作時，畫回格子上，不會站在椅子上揮手。
- **座位**：

  | 位置 | 座位（原圖像素） | 動作 |
  |---|---|---|
  | 酒館 a 桌 | 左椅 (185,662) | 面右 |
  | 酒館 b 桌 | 右椅 (933,665) | 面左 |
  | 酒館 c 桌 | 左椅 (300,840) | 面右 |
  | 酒館 d 桌 | 右椅 (810,827) | 面左 |
  | 廚房 | 左邊高腳椅 (705,830) | 正面坐 |
  | 遊戲室 | 小坐墊 (1215,905) | 正面坐 |

## 3. 坐下來吃飯、零食桌、冰箱

### 3.1 坐下來吃飯（廚房餐桌、酒館四張餐桌）

1. **坐下**：點餐桌，她走過去坐上椅子。
2. **選吃的**：視窗停在她的另一邊（看得到她坐著），列出揹包裡能吃的東西，她喜歡的排前面、粉紅框。
3. **吃一樣**：點了就送 host 的 `feed`。
   - 她頭上冒出那個食物，慢慢往上飄。
   - 吐司顯示恢復多少，她說一句話（坐著說）。
4. **飽了**：按鈕變灰，寫「她現在吃不下了」。
5. **揹包沒吃的**：有「🧊 去冰箱找找」「🍳 去爐子做料理」兩個按鈕。在廚房的話她會直接走過去，在別的地方就告訴主人在哪。

### 3.2 零食桌（遊戲室）

- **免費零食**：坐上小坐墊，上面多一盤免費零食，每天 3 份，跨日補滿。
- **一份的效果**：🍙 +12、⚡ +6、❤ +1，算在每日好感上限裡。
- **吃完了**：盤子上的零食變灰，按鈕鎖住。
- **揹包裡的東西**：下面一樣可以吃。

### 3.3 冰箱（廚房）

- **打開動畫**：門晃一下 → 打開 → 冷光亮起來。
- **每天第一次**：會找到一樣東西放進揹包，例如起司、果醬、番茄 ×2、野莓 ×3。
- **今天找過了**：再打開是空的，她說「明天再來」。
- **拿出來吃**：下面列出揹包裡的食物，可以直接吃。
- **她的位置**：冰箱開著的時候，她站在冰箱前面，不亂走。

### 3.4 資料（`leisure.json`）

```jsonc
"snacks": { "snack": { "name": "零食桌", "emoji": "🍪", "perDay": 3, "satiety": 12, "stamina": 6, "affection": 1, "lines": [...] } },
"fridge": { "perDay": 1, "finds": [{ "item": "food_cheese", "weight": 3 }, { "item": "crop_tomato", "weight": 3, "count": 2 }, ...],
            "lines": { "found": ["冰箱裡有{item}！冰冰涼涼的～"], "empty": ["冰箱說：明天再來吧。"] } }
```

### 3.5 host 規則（`gameplay.ts`）

| 動作 | 檢查 | 結果 |
|---|---|---|
| `{ type: 'snack', table }` | 有這張桌子；今天還有份；她在（`NEEDS_HER`）；還吃得下 | 加飽食、體力（不超過飽食決定的上限）、好感（每日上限）；事件 `snacked { satiety, stamina, gain, left, levelUp? }`。吃完 `sold_out`、太飽 `full` |
| `{ type: 'fridge' }` | 今天還能找嗎 | 用存檔的亂數照 weight 抽一樣，放進揹包；事件 `fridge_opened { item, count, left }`。找過了還是可以打開，`item: null` |

- **存檔**：`pantryToday: { day, snacks: { 桌子: 已吃份數 }, fridge: 已找次數 }`，跨日歸零，壞掉的資料讀成空的。
- **畫面讀的資料**：`stats.pantry: { snacks: { 桌子: 剩幾份 }, fridge: 剩幾次 }`。

## 4. 時間與天氣木牌（HUD）

畫面右上角常駐一塊木牌：

```
┌───────────────────────────┐
│ ☀️   ❄ 冬季 第 1 天        │
│ 晴天 🕒 下午 14:00          │
└───────────────────────────┘
```

### 4.1 設定（`scenes.json`）

```jsonc
"hud": { "clock": {
  "board": "assets/ui/hud-board.png",
  "icons": { "src": "assets/ui/weather-icons.png", "size": 96, "names": ["sunny", "rainy", "storm", "snow"] },
  "corner": "top-right", "nightFrom": 18, "nightTo": 6,
  "seasonIcons": { "winter": "snow" }
} }
```

- **木牌**：用擁有者的圖去綠幕（`tools/key_green.py`）。判斷方式是「跟背景綠色的距離」，所以藤蔓的黃綠色葉子留得住。
- **天氣圖示**：四格，各自置中縮到 96×96。雪花當冬天的季節圖示；其他季節用 emoji。

### 4.2 資料綁定

木牌從遊戲狀態讀這幾項：

| 木牌上的資訊 | 遊戲狀態 |
|---|---|
| season | `view.game.season`（`{ id, name, emoji, day, days }`） |
| day | `season.day` |
| timeOfDay | `view.now`，換算成「早上／下午／傍晚／夜晚 HH:MM」 |
| weather | `view.game.weather` |

- **新狀態**：host 每回傳一次（`setView`）就 `bind` 一次。
- **分鐘**：中間每秒用「上次的遊戲時間＋過了多久」更新。
- **會馬上更新的情況**：快轉時間、睡覺跳到隔天、天氣突變，都會送新狀態過來。
- **純函數**：`clockFace(def, { now, season, weather })` 在 `src/shared/clock-hud.ts`，有單元測試；畫面在 `src/client/pixel/clock-hud.ts`。

### 4.3 特效

- **晚上（18:00～6:00）**：木牌蓋一層藍色（用木牌圖當遮罩，只蓋在木牌形狀上，1.2 秒淡入），字變成米白色加深色描邊。
- **天氣切換**：圖示縮放彈跳一次，0.55 秒（1 → 1.38 → 0.86 → 1.08 → 1）。第一次出現不跳。
- **減少動態**：系統設了「減少動態」就不跳、不淡入。
- **疊放順序**：木牌在畫布後面、黑幕和對話框前面，所以換場景的黑幕、對話框會蓋過它。
