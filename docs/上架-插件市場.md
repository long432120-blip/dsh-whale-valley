## 2. 步驟一：發佈到 npm（需要你的 npm 帳號）

> 這台電腦的 PATH 裡**沒有 `npm`**（只有 DSH 內建的 `node` 與 `pnpm`）。兩條路：
> **A.** 裝一次 Node.js 官方版（<https://nodejs.org>，會一起裝 npm），然後照下面跑。
> **B.** 直接用內建的 pnpm，指令在第 6 節。
> 我已經用 pnpm 跑過一次 `publish --dry-run`：`📦 dsh-whale-valley@0.25.0 → https://registry.npmjs.org/`、`Skip publishing (dry run)`、exit 0，打包內容沒問題。

```powershell
cd C:\Users\<使用者>\Desktop\dsh-whale-pet

# 1) 先確認要發的版本（改版時這裡要同步改）
npm version 0.25.0 --no-git-tag-version   # 已經 0.25.0 就不用跑

# 2) 登入（會開瀏覽器；沒帳號先 https://www.npmjs.com/signup）
npm login

# 3) 確認打包內容沒變（會印出檔案清單）
npm pack --dry-run

# 4) 發佈
npm publish --access public
```

發佈後驗證：

```powershell
npm view dsh-whale-valley version
dsh plugin --profile web add dsh-whale-valley
```

> 之後每次改版：`npm version patch|minor` → `npm run build` → `npm publish`。市場索引會跟著版本更新，PR 不用再提一次。
> 2FA 帳號在 `npm publish` 時會要 OTP，照指示輸入即可。

## 3. 步驟二：提 PR 到 awesome-dsh-plugin（需要你的 GitHub 帳號）

1. 開 <https://github.com/awesome-dsh-plugin/awesome-dsh-plugin> → Fork
2. 在 `README.md`（和 `README.zh.md`，如果有中文條目習慣）的 **Just for Fun** 分類，找字母序位置加一行：

```markdown
- [long432120-blip/dsh-whale-valley](https://github.com/long432120-blip/dsh-whale-valley) - Pixel-art town life sim with a whale-girl companion inside DeepSeek Harness: fishing, farming, ranch, townsfolk, tavern, four seasons, AI diary and mailbox/local-market social features, plus zero external CDN requests. A left-sidebar entry opens the game in its own window so DSH is never covered.
```

3. 開 PR，標題例如 `Add dsh-whale-valley to Just for Fun`
4. PR 描述可以貼：

```
## What it is
A pixel-art farming / town-life sim (鯨魚谷物語) as a DSH plugin: fishing, farming,
ranch, NPCs, tavern, four seasons, tasks, an AI diary (optional DeepSeek key, host-side only),
and local co-op via invite / stall / adoption codes. It also runs standalone in a browser.

## Why it meets the listing bar
- Declares `dsh.bundle.patch` → `cordis.patch.yml`; installs with `dsh plugin add` (tgz or `github:`)
- Ships prebuilt `lib/` so no build step is needed for installs
- Works offline: `npm run check:offline` (no Google Fonts / CDN / Firebase / GA)
- No API key ever reaches the browser: the key is host-only, browser requests carry only
  `{ speaker, trigger, event id }`, and `npm run check:secrets` scans the whole tree
- Left-sidebar entry + own window on Windows (Chrome/Edge `--app`), so it doesn't overlay DSH

## Install
`dsh plugin --profile web add dsh-whale-valley`   (npm, after publish)
`dsh plugin --profile web add github:long432120-blip/dsh-whale-valley`
```

> 分類也可以放 **Just for Fun**（現在就是）；如果你想強調「遊戲」，那個分類底下的例子（desk pet、live2d、鋼琴導航）也都是「好玩」類，屬性一致。
