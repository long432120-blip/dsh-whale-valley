# V0.18 設計書：她的小願望、7 天數值模擬＋試玩、三個微交互

這一版做了三件事：

1. 「她的小願望」：把現有玩法串成每天上線的理由。
2. 7 天數值模擬和完整試玩，找出問題並修掉。
3. 發布前的三個微交互：摸摸頭、季節粒子、現實時間提醒。

---

## 1. 她的小願望（`wishes.json`）

每天早上她會許一個小願望，例如：

- 「今天好想吃蜂蜜鬆餅～」
- 「想跟主人一起釣 3 條魚！」
- 「好想去海邊吹吹風～」
- 「可以……摸摸我的頭嗎？」
- 「我們送個禮物給小葵好不好？」

願望用的都是現有的玩法。主人幫她實現了就加好感，也會寫進當天的日記。

### 1.1 資料

```jsonc
{
  "afterQuest": "tutorial",            // 新手教學做完才開始許願
  "lines": { "new": ["主人主人，{wish}"], "done": ["願望實現了！謝謝主人～"] },
  "wishes": [
    { "id": "eat-cook", "event": "fed", "emoji": "🍳", "text": "今天好想吃{item}～",
      "items": ["food_pancake", "food_omelette", ...], "affection": 6, "hint": "在廚房做料理…", "weight": 3 },
    { "id": "fish", "event": "caught", "count": 3, "text": "想跟主人一起釣{n}條魚！", ... },
    { "id": "beach", "event": "enter", "scene": "beach", "text": "好想去海邊吹吹風～", ... },
    { "id": "gift", "event": "gifted", "npcs": ["fisher", "florist", ...], "text": "我們送個禮物給{npc}好不好？", ... }
  ]
}
```

- **完成條件 `event`**：跟任務系統一樣，用動作的事件（`fed`、`caught`、`harvested`、`planted`、`bathed`、`play_stopped`、`gifted`、`talked`、`placed`、`mine_returned`、`headpat`）或 `enter`（走進某張地圖）。
- **要做的事**：有 `items` 就抽一樣，要是那樣東西才算；有 `npcs` 就抽一位；`count` 是要做幾次。
- **目前 15 種願望**。

### 1.2 規則（host 權威）

```
tickGame(g, now):                         # 每次結算時間
  if 有 wishes.json and g.wish.day != 今天:
    g.wish = rollWish(…, 存檔的亂數)       # 照權重抽、不跟昨天一樣、新手教學時不許

applyAction(g, a):                        # 每個成功的動作
  …原本的規則…
  g = progressWish(g, triggerOf(事件))

setScene(s, sceneId):                     # 走進地圖
  g = progressWish(g, { event: 'enter', scene: sceneId })

progressWish(g, t):
  if 願望沒完成 and 事件種類對 and (物品／居民／地圖對):
    progress += t.count
    if progress >= need:
      done = true
      好感 += affection   # 不算在每日好感上限裡：這是特別的獎勵
      金幣 += coins
      今天的紀錄.wish += 1   # 日記第二重要的事（只比結婚低）
```

### 1.3 畫面

- **側邊欄**：任務下面多一張粉紅色卡片「💭 她的小願望」，寫願望內容、進度和獎勵（❤ +5）。實現了就變綠色、寫「✅ 實現了！」。點卡片她會再說一次怎麼做。
- **新的願望**：早上第一次看到時，她頭上的氣泡會說「主人主人，○○」。每個願望只說一次，記在瀏覽器裡。
- **實現時**：跳出提示、冒出愛心粒子，她說「願望實現了！謝謝主人～」。
- **AI 對話**：她知道自己今天的願望，提示詞多一行「你今天的小願望：……（主人已經幫你實現了）」。

## 2. 7 天數值模擬＋完整試玩

### 2.1 模擬（`npm run sim` → `scripts/sim-week.ts`）

用規則層模擬三種玩家，從春天第 1 天玩 7 天（新手教學已做完，拿到教學獎勵）：

| 玩家 | 每天做什麼 |
|---|---|
| casual | 早上上線一次：摸頭、釣 3 條魚、把她餵飽就走 |
| farmer | 種 5 塊田（收成→澆水→補種→賣菜）、釣魚到體力剩 30、泡澡、晚上再餵一次 |
| gambler | farmer 做的事，加上晚上去酒館：猜硬幣、跟三位居民玩牌、零食桌、冰箱 |

**調整前**（飽食每小時 -4）：
- casual 第 2 天起，每天早上飽食度都是 0：體力上限減半，好感每天 -5。
- 只是一天上線一次的人，每天都要準備約 3 份食物，不然她就挨餓。

**調整後**（飽食每小時 -3，見 2.3）：

| 第 7 天 | 金幣 | 好感（等級） | 最低飽食 | 願望完成 |
|---|---|---|---|---|
| casual | 330（不賣東西） | 76（熟悉） | 33 | 1/7 |
| farmer | 2,315 | 134（好朋友） | 39 | 6/7 |
| gambler | 2,485 | 165（好朋友） | 29 | 6/7 |

**金幣**：
- 收入：認真玩每天約 +300～650。
- 可以花錢的地方總共約 44,000：解鎖 17,800、建築升級 8,000、家具 48 件共 18,600。
- 全部買完要 2～3 個月。這是不錯的長期目標，而且解鎖會讓收入變多。

**好感**：
- 每天的來源：摸頭 +3、願望 +3～8、餵食 +6～14、泡澡 +3、酒館 +6、零食 +3。
- 好朋友（90）：第 4～5 天。
- 求婚（300）：大約第 12～14 天。

**體力**：認真玩的人睡前還剩 70～90。晚上吃東西會補體力，所以體力幾乎不會擋住玩家，限制玩多少的其實是主人有多少時間。

### 2.2 試玩（12 張地圖，白天、晚上各截一張）

| 發現 | 處理 |
|---|---|
| 閣樓、溫室外面的黑色空白可以走：晚上她走出閣樓，站在虛空裡 | **已修**：所有圖層都是空的格子一律擋路（`tiled.ts`）；加了測試 |
| 日記把「空罐子」當成魚（「第一次釣到空罐子」） | **已修**：釣到垃圾不記 |
| 第一次釣到某條魚時，日記會寫兩次（「第一次釣到小蝦。釣到 1 條魚，有小蝦。」） | **已修**（V0.17 尾聲） |
| 一天上線一次的人，她每天早上都餓到 0 | **已調整**：飽食每小時 -4 → -3 |
| 季節粒子太小，春天、秋天幾乎看不到 | **已調整**：花瓣、落葉改成 2～3 像素，數量多一點 |

| 「想吃○○料理」的願望，有些要當季食材，可能當天做不到 | **未處理**：做不到也沒有懲罰，隔天會換 |

## 3. 微交互

### 3.1 摸摸頭

**偽代碼**：

```
leisure.json → headpat: { clicks: 3, windowMs: 1500, affection: 1, perDay: 3, lines: [...] }

onPointerDown(e):
  if 點到她:
    taps = taps 裡 1.5 秒內的 + [現在]
    if taps.length >= 3 and 距離上次摸頭超過 0.8 秒:
      taps = []
      取消還沒說的「點一下說話」
      headpat()
      return
  …原本的點擊（對話框開著就關掉、點家具、點地面…）
  點到她 → petTapped()

petTapped():                         # 單點還是說話，但先等 0.38 秒，確定不是在連點
  clearTimeout(talkTimer)
  talkTimer = setTimeout(talk, 380)

headpat():
  她停下來、轉正面
  burstHearts(10)                    # 愛心粒子
  showLine(pick(headpat.lines), 'happy')   # 專屬台詞池隨機抽一句，播開心的動作
  res = await host.act({ type: 'headpat' })
  if res.gain: 提示「🤚 摸摸頭：❤ +1（今天還能加 2 次）」

# host
case 'headpat':
  n = 今天摸過幾次
  gain = n < perDay ? min(affection, 今天還能加的好感) : 0    # 摸夠了還能摸，只是不加
  headpatToday = { 今天, n + 1 }
  → 也算「摸摸我的頭」的願望、寫進日記
```

**愛心粒子**：用 5×4 的像素愛心點陣。從她頭上往外噴，初速隨機往上，每幀乘 0.96 慢慢減速；最後 40% 的時間淡出，1.1～1.7 秒消失。

### 3.2 季節粒子（`client/pixel/season-fx.ts`）

**偽代碼**：

```
scenes.json → ambient.seasons:
  spring: petal   粉紅 2～3px  34 個  往下 9～17px/s   搖擺 5～12
  summer: firefly 黃綠 1～2px  24 個  -4～2px/s（會往上飄）  白天只有 35%
  autumn: leaf    橘紅 2～3px  26 個  往下 11～20px/s  搖擺 8～18（一下橫一下直＝翻轉）
  winter: snow    白   1～2px  50 個  往下 9～19px/s   搖擺 2～7

每一幀（finishDraw）:
  fx.set(季節, { outdoor: 戶外地圖?, night: 傍晚或晚上?, rain: 有下雨粒子? })
    target = count × (白天? dayRatio : 1) × (下雨? rainRatio : 1)    # 室內 = 0
  fx.update(dt):
    第一次 → 一口氣生成 target 個，散在整個畫面（不會一排一起落下）
    之後每幀最多補 2 個，多的砍掉
    每個 p.y += p.vy × dt
    掉出畫面（螢火蟲：活滿 6～10 秒）→ 在上方重生
  fx.draw('normal')   # 在時段濾色之前畫：晚上跟著變暗
    x = p.x + sin(t × freq × 2 + phase) × sway        # 左右搖擺
    螢火蟲：alpha = 淡入淡出 × (0.55 + 0.45 sin(3t))   # 一閃一閃
    fillRect(x, y, size, size)                         # 地圖座標的像素方塊，放大後就是像素風
  時段濾色
  fx.draw('glow')     # 晚上的螢火蟲畫在夜色上面，旁邊多一圈淡淡的光
```

雨天時，櫻花、落葉只剩 25～30%（被雨打掉）；雪照下。

### 3.3 現實時間聯動（`shared/late-night.ts`）

**偽代碼**：

```
scenes.json → ambient.lateNight: { fromHour: 23, toHour: 5, repeatMinutes: 60, maxPerNight: 3, lines: [...] }

每 30 秒（開畫面 6 秒後先檢查一次）:
  if 忙、對話框開著、視窗開著、她不在: 下次再說（不打斷主人）
  now = new Date()                 # 玩家電腦的時鐘，不是遊戲時間（遊戲可以快轉，主人可不行）
  night = 晚上那天的日期（0～5 點算前一天晚上）；不是深夜 → 不提醒
  st = localStorage 裡這一晚的紀錄
  if st.count >= 3 → 不提醒
  if st.count > 0 and 距離上次 < 60 分鐘 → 不提醒
  記下 { night, count + 1, last: now }
  她停下來、轉正面，showLine(「主人，現實裡已經很晚了，我們早點休息吧！」, 'sleepy')
```
