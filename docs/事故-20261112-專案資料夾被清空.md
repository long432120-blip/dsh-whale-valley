## 3. 最可能的原因

被刪的資料夾正是 profile 依賴 `dsh-whale-pet@link:C:/Users/<使用者>/Desktop/dsh-whale-pet` 的**連結目標**。
pnpm／plugin-manager 在解除一個 `link:` 依賴（或把它換成別的來源）時，把連結目標目錄的內容一起刪掉了。
在 Windows 上，對 junction／目錄符號連結做遞迴刪除時「跟進目標」是已知的危險行為。

**尚未做決定性的重現測試**（使用者叫停）：測試方法是拿一個臨時資料夾當假插件、用同樣的 link→remove→tgz 流程跑一次，看目標資料夾會不會被清空。
建議在把插件放上 dsh-market 之前務必重現確認，並在插件說明加上「不要用 `dsh plugin add <你的原始碼資料夾>`，要就裝 tgz／github」。
